# 专业模块

8 个专业创作模块：按阶段一次只调用一个，防止编剧、视觉、表演和视频提示词方法互相污染。

## 本目录文件

- **01-概念锚定.md**（7KB）：故事大纲（Synopsis）模块。A/B/C/D 项目定位主菜单硬门禁 + 多轨模板（长片 13 项结构 / 艺术片三层结构法 / 爆款网剧强爽感引擎 / 高阶自定义）。
- **02-角色圣经.md**（6KB）：角色圣经模块。与大纲绑定继承风格基因；A/B/C/D 四条角色模板路径（经典 / 艺术片 / 网剧 / 自定义），含声音可辨测试。
- **03-世界观-可选.md**（4KB）：世界观/神话设定模板（俄文版式），现实题材可跳过；含世界规则、系统、历史、势力、地点、神器、信息层级等。
- **04-分场大纲.md**（8KB）：分场大纲模块。只写物理动作不写对白；B/C 先按体量问场景总数；每场写时长预算；含逐场检查原则与审计标签。
- **05-剧本深度融合与排版.md**（13KB）：专业剧本模块。逐场锁定硬边界；A/B/C/D 格式路线；对白处理（保留 / 专业扩写 / 仅润色）；分批输出与保存。
- **06-Lira图像资产.md**（22KB）：Lira 图像提示词优化专家。4-D 方法论、工具分工、纯中文提示词规范、资产咨询与修改隔离规则。
- **07-ACTING表演.md**（29KB）：表演系统（Seedance 2.0）。五大支柱、倾听与反应、身体物理生命、台词声音、表演档案；最终提示词 100% 纯中文。
- **08-CINEDANCE视频提示词.md**（43KB）：CINEDANCE V5 专业镜头规划与双模型提示词系统。镜头规划门、两次计时、中文对白安全预算、连续性编译、Seedance 2.0 适配与 MiniMax H3 独立适配器。
- **_索引.md**：本目录索引，列出以上 8 个模块。
