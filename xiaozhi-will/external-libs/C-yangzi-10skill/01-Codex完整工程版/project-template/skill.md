# project-template

AI 影视项目文件夹模板：弹性总控 + 十个编号阶段目录，新项目由"新建AI影视项目.ps1"复制生成，模板内不包含任何示例故事内容。

## 本目录文件

- **AGENTS.md**（5KB）：AI 影视项目弹性总控。规定新项目第一轮判断入口 A 从零 / B 完整剧本 / C 部分资料 / D 高手镜头优化（只问一次）；一次只调用一个专业 Skill；08 阶段内部固定两步（先在 05_shots 完成镜头规划并确认，再在 06_prompts 输出 Seedance 2.0 / MiniMax H3 / 双版本提示词）；每条提示词必须独立写全连续性、禁止"上一镜头/继续/同上"；知识桥默认未调用；跨阶段参考记忆规则；01 与 05 强制检查。
- **_索引.md**：本目录索引，列出 00_inbox 至 08_delivery 十个子目录与 AGENTS.md。

## 子目录

- **00_inbox**：项目收件箱/暂存区（放用户最初投入的资料）。
- **00_project**：项目控制区（brief、项目状态、路由、跨阶段参考记忆）。
- **01_story**：01 概念锚定阶段产出目录。
- **02_script**：02 角色圣经 / 剧本阶段产出目录。
- **03_assets**：06 Lira 图像资产阶段产出目录。
- **04_performance**：07 ACTING 表演阶段产出目录。
- **05_shots**：08 CINEDANCE 镜头规划目录（含 keyframes 关键帧子目录）。
- **06_prompts**：08 已确认镜头的 Seedance / H3 提示词输出目录。
- **07_generations**：生成成果存放目录（空目录模板）。
- **08_delivery**：最终交付物目录（空目录模板）。
