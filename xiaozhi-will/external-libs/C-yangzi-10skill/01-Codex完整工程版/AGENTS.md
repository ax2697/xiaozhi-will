# AI STUDIO 洋子课程包安装总控

本文件夹是纯工程安装包。用户不需要手工复制 Skill。

推荐安装方式：用户把 ZIP 下载到“文档/AI STUDIO洋子AI电影工作流/课程安装包”，用 Codex 新建本地任务并选择这个文件夹，或把 ZIP 直接拖进 Codex 聊天窗口，然后用中文要求安装。由 Codex 自动解包并进入本工程执行安装；不要要求小白手工解压或复制 `.codex/skills`。不要把课程安装包当作电影项目，也不要在这里创作剧本。

## 用户说“安装课程包”时

1. 如果当前输入是 ZIP，先在课程安装包目录内自动解包，再进入解包后的 `01-Codex完整工程版`；不要要求用户手工解压。
2. 说明：即将把本工程内 10 个 Skill 安装到当前用户的 Codex Skill 目录；其中包含原 9 个电影 Skill 和 1 个本地知识库外挂，如发现同名旧版本，会先备份再更新。
3. 执行 `scripts/安装课程包.ps1`。不要要求用户自己寻找、删除或复制 `.codex/skills`。
4. 如果 Codex 请求系统目录写入权限，用简单中文说明“点击允许即可完成安装”。
5. 安装后检查 10 个 Skill 文件夹及各自的 `SKILL.md` 是否存在。
6. 成功后只回复：安装完成、已安装数量、是否产生备份、下一句可输入的中文口令。

Windows 执行 `scripts/安装课程包.ps1`；macOS 或 Linux 执行 `python3 scripts/install_course.py`。不要让 Mac 学员安装 PowerShell。

## 用户说“配置本地知识库”时

1. 让用户选择知识库根目录，或直接选择 `curated-screenplay-methods.sqlite`；不要要求手工填写 JSON。
2. Windows 执行 `scripts/配置本地知识库.ps1 -KnowledgeRoot "所选路径"`。
3. macOS 或 Linux 执行 `python3 skills/film-knowledge-bridge/scripts/configure_knowledge_base.py "所选路径"`。
4. 检查输出中的文档数和片段数。配置成功后告诉用户：该电脑上的所有电影项目都会自动共用，不需要重复选择。
5. 知识库可在任意盘符、外接硬盘或 Mac 文件夹；不存在固定 `G:` 要求。

## 用户说“更新本地知识库”时

1. 先确认知识库已经配置；未配置时先按上一节让用户选择一次文件夹。
2. Windows 执行 `scripts/更新本地知识库.ps1`；macOS 或 Linux 执行 `bash scripts/更新本地知识库.command`。
3. 只索引新增或修改过的 PDF、Word、Markdown、TXT，不重复处理未变化文件。
4. 在聊天中报告扫描数、新增数、更新数、未变化数、失败数和报告路径。扫描版 PDF 无文字时明确提示 OCR，不得声称成功入库。
5. 这是扩充本机可检索资料，不是训练或修改大模型。知识库路径可与作者电脑不同。

## 用户说“整理新剧本并更新知识库”时

1. 这是明确的本轮整理授权。读取已安装 `film-knowledge-bridge/references/inbox-workflow.md`，不得把它误当成知识库 A/B/C 检索菜单。
2. 从配置中读取该学员自己的知识库根目录，并创建或使用 `90-隔离与待审/新加入待分类`；不得套用作者电脑盘符。
3. 入口为空时，只在聊天中显示实际完整路径，让学员把网盘下载的剧本或编剧书放进去后重复同一句口令。
4. 入口有文件时，按规则安全解压、去重并分类；无法可靠判断的留在待人工确认，不删除、不覆盖、不移动知识库外文件。
5. 整理完成后运行增量索引，并报告分类、重复、待确认、压缩包、OCR 和索引结果。

## 用户同时要求创建电影项目时

安装成功后执行 `scripts/新建AI影视项目.ps1`。只询问一次“电影项目标题是什么？”，不要求小白填写磁盘路径。保存位置默认使用当前用户“文档”目录下的 `AI STUDIO洋子AI电影工作流/电影项目/项目标题`。

示例中文口令：

```text
安装这套课程包，并新建电影项目。
```

如果用户尚未给出标题，先问：

```text
电影项目标题是什么？
```

完成后告诉用户用 Codex 打开新项目文件夹，然后输入：

```text
启动项目：我要做一部60秒竖屏悬疑AI短片。
```

## 用户要求升级已有电影工程规则时

如果当前任务打开的是安装包，先执行 `scripts/安装课程包.ps1` 更新当前用户的 10 个全局 Skill。之后让用户为旧电影项目新开一个 Codex 本地任务，并打开原电影项目文件夹。

更新后的 `ai-film-router` 已自带旧项目升级能力。用户在旧项目任务里输入“升级当前电影工程到新版规则”时，按该 Skill 自身的升级流程执行；不要求用户返回安装包寻找脚本。

升级前要用简单中文说明：只会备份并更新项目根目录 `AGENTS.md` 与 `00_project/routing.md`；如果项目没有 `00_project/reference-memory.md`，只新增空白模板，已有参考记忆不覆盖；不修改故事、角色、剧本、资产、表演、提示词、历史版本或其他创作成果。

示例中文口令：

```text
升级当前电影工程到新版规则：先备份旧规则，再更新 Skill 和项目规则；不要改动任何剧本、角色、资产与历史文件。
```

## 边界

- 安装时按包内 V3 定稿原样部署 10 个 Skill，不在学员电脑临时改写规则；`film-knowledge-bridge` 仍只作为可选检索外挂。
- 不把教案、学员手册、课程图片安装进 Codex Skill 目录。
- 不同时执行多个创作 Skill；电影项目由 `ai-film-router` 单阶段推进。
- 知识桥不是第 09 个创作阶段，默认状态为“未调用”。只有用户明确说“调用本地知识库、知识库B、知识库C、匹配本地参考”或同义口令时才显示或执行知识库选择；未调用时不得提示、检索或写参考记忆，原 9 个 Skill 完全照常工作。
- 已经由用户确认并写入项目参考记忆的故事方法，默认使用范围为“故事创作（01-05）”。进入 05 时必须自动加载，不重新搜索；用户增加、停用、恢复或替换参考时先实时写回项目文件。
- 06 Lira 与 08 CINEDANCE 默认不提示检索；只有用户明确要求视觉考据、电影美术、镜头、声音、剪辑或动作连续性方法时才调用知识桥。07 ACTING 可按需推荐表演、导演、潜台词与场面调度书籍。
- 新项目先记录 A 从零、B 完整标准剧本、C 部分资料或 D 高手镜头优化。B 只补生产资料，不擅改作者剧本。
- 08 先在 `05_shots/` 完成镜头规划并等待确认，再在 `06_prompts/` 输出 Seedance 2.0、MiniMax H3 或双版本；这仍是原 08 阶段。
