## 〇 · 立场景之形（道教口径）

> **16 项是「形」，六锁是「界」，调色是「色」。**
> 形不立，拍不了；界不定，接不上；色不配，看不懂。

## 二、CINEDANCE 六把锁（英文短句，供 P4 复制）

> 每场景一套，跨集复用。改需登记。写法见 `references/15-cinedance-six-locks.md`。

### ① 首帧占用

```
Frame 0: 【谁】 fills the 【centre/left/right】 third, 【head-and-shoulders / full body】 in frame, 【朝向】.
```

### ② 空间调度

```
Spatial: 【@码】 stands 【X meters】 from 【锚点物】, facing 【camera-left/right】; 【@码2】 holds 【位置】 at 【X meters】 behind, facing 【方向】.
```

### ③ 视线-朝向分离

```
Gaze: head angled 【X degrees】 【camera-left/right】; eyes locked on 【具体对象】, not 【对象】.
```

### ④ 地标邻近

```
Landmark: 【身体部位】 sits within 【X cm】 of 【画面内可见参照物】; 【道具】 rests 【位置】 at 【高度】.
```

### ⑤ 多镜连续性

```
Continuity: keep 【服装状态】, 【持物】, and 【光向】 across all shots in this group.
```

### ⑥ 上下文隔离

```
Sealed: this shot contains only 【@码列表】; no other characters, no furniture from the previous scene.
```

## 五、FOV° 与机位对照（本场景常用）

| 机位 | FOV° | 可见结果短语 | 用途 |
|:---:|:--:|:---|:---|
| CAM1 | 【29°】 | natural human-eye perspective, no edge distortion | 常规叙事 |
| CAM2 | 【18°】 | shoulders and background sit within 30 cm of apparent depth | 对话正反打 |
| CAM3 | | | |
| CAM4 | | | |

> FOV° 六档：8 / 18 / 29 / 47 / 84 / 107。**不用 mm。** 长焦类（8/18/29）至少写 4 个视觉结果，广角类（84/107）至少 3 个。
