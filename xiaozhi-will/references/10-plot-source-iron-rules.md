# 十、剧情来源与改编铁律 · 写改剧本先回查剧情源，保证剧本与源头一模一样

> **唯一作用 · 最高铁律：**剧情源（原著 / 用户剧本 / 大纲）**只用来"看剧情"**，是剧情的唯一来源与最高依据。**剧情高于一切、一切以剧情源（剧本）为主**——剧本严格按剧情源走，对人物 / 事件 / 先后顺序 / 因果 / 关键台词原意 / 信息点**不添加、不更改、不删除**（一个不增、不改、不丢），不杜撰、不跑偏、不提前植入后续章节。唯一允许的只是"形式等量转换"：把叙述改成可拍的动作△ / 画外音 VO / 镜头拆分，**不增减任何剧情信息**；拿不准以剧情源原文为准，**剧情源没写的一律不写**。诺兰式电影化呈现手法（非线性 / 闪前闪回 / 交叉蒙太奇 / 片尾双钩 / 集首冷开场等）属"形式等量转换"的电影化延展，见白名单 B 类与第八章基石地基——只改呈现、不改剧情。

> **唯一授权改编白名单（用户亲自拍板，凌驾三不；名单封闭，只有用户能加，AI 不得自行扩充）：**
> **A 类 · 内容层白名单（剧情实体级）**：① **【A 类授权：写用户点名的新剧授权，如"某角色→某设定全局替换"；无则写"无"】**（2026-xx-xx 定），只作视觉 / 战力叠加，**不改变剧情源事件顺序与结果**。
> **B 类 · 电影化呈现白名单（诺兰式手法，依第八章基石地基建立；原则式授权＝自动覆盖任何具体用法，不再逐项点名申报）：**
> **判定标准（是否属 B 类，一问即决）**：该手法是否只改变"如何呈现"、而没有增 / 改 / 删剧情事件本身（人物 / 事件 / 因果 / 关键台词 / 信息点）？是＝直接可用；否＝属剧情篡改，回退三不、先报用户。
> **统一边界（任何手法都必须同时满足）**：① 事件因果顺序不变，呈现顺序可任意编排；② 关键台词原文三不动、信息点不增不删；③ 素材来源真实——本集章用【切文脚本】切第 N 章、跨章钩子用【切文脚本】切对应章，禁止杜撰；④ 除跨章钩子外不引用本集章以外剧情。
> **允许的手法族（自动覆盖具体用法）**：① **非线性时间呈现**：闪回 / 闪前 / 插叙 / 倒叙；② **跨章钩子**（集首冷开场 ＋ 集尾预告蒙太奇，诺兰片尾双钩）：集首可用相邻后续章开篇做"叙说 / 闪前冷开场"，集尾可用次章开篇做"下集预告"，各 ≤15s、只做钩子不展开不推进剧情、新人物仅预告性亮相不出演剧情、字幕诚实标注（"下集预告" / "本集自第 N 章叙起"）；③ **交叉蒙太奇 / 双线并置**：本集章内两线交叉剪辑、同点汇聚；④ **匹配转场**：声音 / 物体 / 动作 / 台词尾词衔接时空跳转；⑤ **母题与符号**：声音母题、光影母题、视觉符号、混响分层（对齐分镜第四章连续性锚点）；⑥ **视角化**：主观受限视角、内心独白 VO、不可靠叙事呈现；⑦ **视听语法**：景别 / 运镜 / 构图 / 画幅 / 光影色调 / 剪辑节奏（纯呈现层，本就自由）。
> **除白名单外剧情一律严格三不，白名单之外任何增 / 改 / 删必须先报用户批准；B 类手法是否越界，一律以本章判定标准与统一边界复核。**

> 剧情源库在 `【项目根目录】\参考\`，总导航＝`参考\00_参考索引.md`；剧情源＝【原著/剧本名（作者，章节数/字数、连载状态）】，短剧名＝【新剧名】。

### 10.2 "剧本对剧情源"标准动作

> **五步闭环：**
> - **①定位章节**：先开《小说总大纲（全剧主纲）》确认所属季/阶段与剧情源章范围（集与章已解绑、按戏剧节奏自由分集），再用结构地图/标题序列核对（本集覆盖章【N】，直接开对应提取文件）
> - **②读原文**：_readseq.py 切该章（或开分片/提取文件）通读，不只看笔记摘要
> - **③逐项核对（三不铁律）**：人物身份、事件先后、关键动作场景、关键台词原意、系统设定/信息点逐条对到剧本，**不添加、不更改、不删除**；只允许把叙述等量转成动作△/画外音VO/镜头，不增减剧情信息；剧情源没写的一律不写，有出入立刻以原文回改剧本（剧情高于一切）
> - **④标注出处**：剧本/分镜备注对应剧情源章号便于复核，有出入以原文为准回改
> - **⑤不越界**：本集只取本集覆盖章，后续章人物/道具/情节不提前出现（对齐总索引 6.4 红线）

### 10.3 命名与语料注意（防被旧体系/坏页带偏）

> 【本剧命名口径：角色名/地名以最新 .md 为准，勿被旧体系或参考库旧命名带偏。语料缺口：若剧情源全本有乱码/缺章/坏页，统一改用切文脚本从干净全本切取；采集留档目录日常不开。】
