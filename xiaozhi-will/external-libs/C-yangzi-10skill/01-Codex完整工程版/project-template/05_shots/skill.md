# 05_shots

镜头规划目录：08 CINEDANCE 阶段第一步的拆镜结果存放处（如 `场次ID-shot-plan-vNN.md` 镜头清单、`场次ID-continuity-ledger-vNN.md` 连续性台账），用户确认后才进入 06_prompts 生成提示词。

## 本目录文件

- **.keep**：占位文件（1B），用于保持空目录结构。
- **_索引.md**：本目录索引，列出 keyframes 子目录与 .keep。

## 子目录

- **keyframes**：首尾帧连续模式所需的关键帧图片（如 `镜头ID-first-frame.png`）存放处。
