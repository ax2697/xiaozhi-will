# 24 · 炼精化气 · 资产三单与出图模板（道教改写）

> **归位**：三阶 · 炼精（P2 资产）
> **来源**：漫剧老李 V7.4.26 `sd-asset-engine`（MIT）
> **改写**：用道教"炼精化气"逻辑重组——**精不凝，气不成形**。

---

## 总纲：三单是分药，出图是成形

内丹讲"炼精化气"：先把散乱之精收拢成团，再化成可运行之气。

资产也是：**散落在剧本里的外观信息 → 收成三单 → 出成可锁定的图。**

> **判据**：**三单没做，出图必错。** 不是"先出图再补设定"，是"先分药再起火"。

---

## 一 · 三单提取：把散落的信息收成三张清单

### 三单是哪三单

| 单 | 内容 | 硬要求 |
|:--:|:---|:---|
| **A · 角色外观** | 每人**一整段连贯文字** | 必须覆盖六要素：**年龄 / 性别 / 肤色 / 发型发色 / 五官特征 / 服装**。⛔ 武器、装备、功能道具**全部移出**（归 B 单） |
| **B · 道具设计** | 按类型分类，每件一张完整设计卡 | |
| **C · 场景设计** | 每场一段 + 空间要素分析 | 「正面全景微俯视**大白话**」+ 空间分析 |

### 提取方法：三步扫描

| 步 | 做什么 |
|:--:|:---|
| **A1/B1/C1 · 文本扫描** | 按类扫描剧本。角色的扫描目标：他人视角观察 / 照镜子 / 整理衣帽动作 / 年龄身高暗示 / 体态步态 |
| **A2/B2/C2 · 信息整合** | 角色围绕六要素；道具填完整卡；场景围绕：空间类型 / 尺度 / 结构 / 地形 / 时间 / 天气光照 / 主色调 / 关键固定物 / 空间纵深 / 声味转视觉 |
| **A3/B3/C3/C4 · 输出** | 三单 + 汇总表 |

### 原文优先三级（不许跳级）

```
① 原文引用  >  ② 可推导（标「推导」）  >  ③ 设计建议（标「设计建议」）
```

> ⛔ **禁止捏造与原文矛盾的特征。**
> 原文说"短发"，你不能因为"长发更好看"就改成长发。

### 人物场分离（最容易混）

| 归哪 | 判据 | 例 |
|:---|:---|:---|
| **角色** | 角色皮肤 / 贴身装饰 | 饰品、眼镜、纹身、疤痕 |
| **道具** | 需单独建模的**可移动物** | 剑、杯、信、手机 |
| **场景** | 搬不走的**环境本体** | 墙、地、天、山、河流 |

> **场景内可搬走的物件 → 归道具单**，但在场景描述里用「此处摆着道具#XX」点明位置，**不重复展开**。

### 场景大白话纪律

| 项 | 规定 |
|:---|:---|
| **固定镜头** | 站在正前方，**俯角 15–25°** |
| **白描顺序** | 站位总述 → 近景地面 → 左右中景 → 由近及远纵深 → 收在光线氛围 |
| **禁止** | 文学腔；把核心描述分项成清单（**要素分析可分项，描述不许**） |
| **巨场景** | 可抬至 30–45°，按前景/中景/远景三层铺陈 |

### 特殊处理

| 情况 | 处理 |
|:---|:---|
| 同角色多套服装 | 同编号 + 状态轨迹 |
| 人外异族 | 并入六要素 |
| 群像 | 只给一段群体文字描述（无图号） |
| 信息匮乏角色 | 明示「最小推导」 |
| 同一道具多持有者 | 共用同一编号 |
| 同一场景多版本 | 同一编号 + 状态轨迹 |
| 半室外 | 须交代「哪部分有顶」 |

## 二 · 角色板：四格定形

### 四格构成

| 格 | 内容 | 硬要求 |
|:--:|:---|:---|
| **①** | 面部特写 | 头部占该格高度 **≥70%**；**五官 10 项锁定** + 皮肤质感 + 收尾写「X~Y 岁男性/女性（身份代称）」 |
| **②** | 正面全身 | **无脸** |
| **③** | 90° 侧面全身 | **无脸** |
| **④** | 背面全身 | **无脸** |

> **②③④ 一律无脸**：头部完整入画，头型 / 发型 / 颈部 / 肩线保留，**面部不刻画五官**。

### 三条铁律

| # | 铁律 | 说明 |
|:--:|:---|:---|
| **1** | **单一面部锚点** | 全图只允许**一张**可辨识的脸，且必须在第 ① 格 |
| **2** | **禁止砍头** | `无头/headless/cropped head` **已废弃**——砍头会致头身比失真 |
| **3** | **只出四格** | 提示词必须显式声明「全图共 4 格、不设独立大主图、不重复视角、不出现第 5 格」 |

> **「主图」一词已废弃**，改称「正面格」。实测"主图 + 四格板"会出成 5 格、正面画两次。

### 禁用词与替代

⛔ **禁用字面** `mosaic / pixelated / 马赛克`——会被渲染成真实像素块。

✅ **必须转译成「无脸」**，工程实现二选一：
- **A：无五官平面**（首选）
- **B：柔和失焦**

### 其他硬要求

| 项 | 规定 |
|:---|:---|
| 全身完整 | 三格全身头顶至鞋全入画，不裁脚不裁头，鞋必须画在全身格内 |
| 零文字 | 图上唯一文字 = 图底 **≤8 词英文音色速览标签** |
| 声纹 | 另设声纹波形/频谱（非文字图形，不算入图文字，**不宣称锁声线**） |
| Voice | 完整版 Voice Description（英文 2–4 句）**必填但不进图**，纯文本交付 |
| 首句 | **必写头身比**（写实"真人 6.5~7.5 头身"），防"头大身小" |
| 立绘纯净 | 只呈现本体 + 穿戴配饰；**禁手持/放置道具**；端正站立，禁坐蹲行走战斗 |
| 整板 | 固定 16:9 横版 |

### 身份外观三件套（S/A 角色必写）

| # | 件 |
|:--:|:---|
| 1 | 职业标识物 |
| 2 | 服装形制与材质（形制 + 材质 + 磨损 + 标志色） |
| 3 | 气质体态**写进身体** |

**配反漂移清单**：写死"**不能画成什么**"。
**年龄写年龄段、体型写数字**，⛔ 禁"高大/健壮"式概括。

### 换装规则

| 项 | 规定 |
|:---|:---|
| 图号 | 每套造型**独立图号、独立一张** |
| 基准 | 第二套起以第一套为**脸型/五官/肤色/年龄/音色**基准 |
| 可变 | 仅服装（含鞋袜、造型配饰、可选发型） |
| 不重复 | **不重复写 Voice Description、不重复渲染标签**，声纹波形沿用同一条 |
| 服装 8 字段 | 类型 / 颜色 / 面料 / 纹样 / 结构 / 状态 / 鞋袜 / 专属配饰。无内容写"无" |

## 三 · 道具板：四角度定物

### 四格版式

| 格 | 视角 |
|:--:|:---|
| ① | 正面视图 |
| ② | 45° 侧视图 |
| ③ | 顶部俯视图 |
| ④ | 关键细节特写 |

**必须显式声明「全图共 4 格」**。不设独立大主图、同一视角不得重复、不得出现第 5 格。

### 与角色板的关键差异

| 项 | 角色板 | 道具板 |
|:---|:---|:---|
| 标注 | **零文字**（只图底 ≤8 词） | **保留**「左上角标注：〔道具名〕」与格内标注 |

> **为什么不一样**：角色板怕文字污染脸部识别；道具板需要标注来对齐台账。

### 其他

| 项 | 规定 |
|:---|:---|
| 整板 | 16:9 横版，四格等大，共享同一造型/材质/色彩/尺寸比例 |
| 纯净 | 禁任何人物、手、肢体、剪影、**倒影中的手**，禁手持展示 |
| 背景 | 纯白或指定场景，不得有人/手 |
| 状态轨迹 | 备注写 `初始→中间→最终`；无变化写"无状态变化" |
| 沿用 | 开头写「与第X集完全一致，禁止重新设计」 |

**提示词内容**：材质 / 尺寸比例 / 造型结构 / 色彩纹样 / 年代风格 / 使用痕迹。

**制作优先级**：⭐⭐⭐ / ⭐⭐ / ⭐

## 四 · 场景九宫格：九视角定空间

### 定位（容易搞错）

> **本模板只管九宫格**（纯场景无人、1 槽 = 9 视角），用于对抗视频模型素材数量上限。
> **母版**（必出第一张）、**机位调度版 / 战斗站位版**（复杂场景按需）归总控，**两类都要出、互不替代**。

**出图顺序**：母版 → 九宫格 → 调度/站位版

### 出图前两步

| 步 | 定什么 |
|:--:|:---|
| **1** | **内容分配模式**：模式 A 单场景多机位 / 模式 B 多子区域分配 |
| **2** | **锁参考图开关**：关 = 首次出现；开 = 延续拍摄 |

### 八字段自检（缺一不合规）

| # | 字段 |
|:--:|:---|
| 1 | 【场景定位】必填空间类型（决定选哪张摄影机表） |
| 2 | 【场景画面描写】完整画面语言，**禁纯名词罗列** |
| 3 | 【九宫格内容分配】 |
| 4 | 【参考场景锁定模式】模式 A 档仅允许摄影机移动；模式 B 档允许按子区域切换机位，**按模式选档不得混用** |
| 5 | 【摄影机矩阵】 |
| 6 | 【摄影机参数】 |
| 7 | 【光照曝光】 |
| 8 | 【标注要求】 |

+ 显式写「**全图共 9 格，不多不少**」+ 整板写 16:9

### 三条硬纪律

| # | 纪律 |
|:--:|:---|
| **1** | **格数纪律**：全图 9 格，不得第 10 格、不得拆散图；标注渲染失败降级后仍须保 9 格结构 |
| **2** | **自包含**：⛔ 禁 `同上/同规格/见母版/同图N/标注要求同图N`——一条提示词的投喂单位是它自己，锁定模式原文、降级条款、光照段**每条重复写** |
| **3** | **机位矩阵先按空间类型选表**：表① 室外独立建筑 / 表② 室内半封闭 / 表③ 自然场地街巷。机位名与空间类型不符必须换替代表，⛔ 禁硬凑（室内"背面全景/高空鸟瞰"、庭院"高空鸟瞰"均判违规） |

### 摄影参数

| 项 | 值 |
|:---|:---|
| 焦段 | 统一 **50mm** |
| 视角 | 平视无畸变 |
| 曝光 | 充足明亮 |
| ⛔ 禁 | 暗调 / 黄昏 / 低照度（剧情需要须显式声明） |

### 标注降级条款

中文渲染失败（乱码/缺字/截断）→ 格内仅留 **1~9 数字** + 图外《编号—子区域对照表》。
**重试上限 2 次**，⛔ 禁无标注裸格交付。

### 其他

| 项 | 规定 |
|:---|:---|
| 画面纯净 | 禁任何人物、人影、肢体、动物 |
| 风格 | 三选一（3D/2D/写实），完整分支段落必须写入 |
| 锁参考图开时 | 追加【延续拍摄声明】+【参考图锁定】（图生图，强度 **0.7–0.85**，元素 100% 保留） |
| 延续 | 【场景定位】【场景画面描写】**逐字复用**首次出现集文字；延续机位优先选上集未用过、角度差异最大的组合 |

## 五 · 连续性四工具

### 工具 1 · 场景空间连续性

**必写五项**：

| # | 项 |
|:--:|:---|
| 1 | 分界面定义：门窗主光在哪个方向 |
| 2 | 侧别命名 |
| 3 | 人物允许区 |
| 4 | 禁止区 |
| 5 | 硬约束句 |

**多角度包**：每个角度单独图号，写清「只参考 / 不参考什么」。**角度图不替代母版。**
**光影变化必须写理由**，且**光源结构保持一致，只变强度与色温**。

### 工具 2 · 道具单实例锁

**四要素**：

```
对应关系 + 数量限制 + 用途限定 + 状态互斥（拿起后原位必须变空）
```

**小道具朝向规则**：

| 情况 | 规则 |
|:---|:---|
| 不需要看屏 | 屏幕朝手心 / 桌面 |
| 需看 UI | 明确屏幕正向并限定 UI |
| 照片证件 | 写清正反面 |
| ⛔ 必须禁止 | "背面变屏幕 / 正反面同时是屏 / 随机 UI 或文字" |

### 工具 3 · 群像资产卡（GRP-N）

**判据一句话**：**这群人"要不要长得一样"？**
- 要 → 建 `GRP-N` 资产卡（锁长相，资产层，P2 出图）
- 不要 → 只写人群密度句（投喂层，无编号）

**触发条件（命中任一）**：跨 ≥2 段 / 承担叙事功能 / 入特写或中近景。

**7 字段卡（缺一不合格）**：

| # | 字段 |
|:--:|:---|
| 1 | 统一制式（⛔ 禁"统一着装"空话） |
| 2 | 年龄与性别构成 |
| 3 | 体态与身高带 |
| 4 | 可辨识度分级：**A 级**有个体脸须逐个 4 View / **B 级**统一制式一张群体图即可 |
| 5 | 数量与密度基准 |
| 6 | 场景绑定 |
| 7 | 状态轨迹 |

**出图规范：一张群像图 = 3 格横向并排**
- 制式细节格 / 3~5 人合影格 / 远景群像格
- **B 级后两格不刻画个体五官**（否则模型会"发明"个体脸，下一段变脸）
- **A 级出戏个体必须先升 `CHR-` 走 4 View**，⛔ **禁用一张群像图硬扛**
- ⛔ 禁在群像图里出现主角

**投喂层锚点** `@群体名`，与 `@人名` 同栏同待遇（七段式不增段）。
**M0 无图时逐段复述制式**，⛔ 禁"同上/同前"。

### 工具 4 · 人群调度卡（仅无辨识度背景人群）

**七项必写**：绑定场景 / 密度等级 / 景深层次分布 / 人群类型 / 移动遮挡规则 / 声音氛围 / 禁止项。

**必须翻译成密度句**：
```
前景 2 名路人、中景 5 名顾客、远景 10 余人，人流左→右，不遮挡主角面部
```

⛔ 禁写「同上一段人群 / 保持之前人流」。
无路人需求时**不新增字段，只写禁止项**。

### 工具 5 · 视觉风格锁

**七项**：风格身份 / 人物审美锁 / 场景审美锁 / 画面质感锁 / 正向词 / 负面词 / 转译短句。

⛔ **编号不进投喂稿**，必须转自然语言。
**风格光影与真实光源冲突时以真实光源为准**，保留媒介质感与反差。

## 六 · 四条贯穿全篇的硬纪律

| # | 纪律 | 说明 |
|:--:|:---|:---|
| **1** | **格数总数声明** | 角色 4 格 / 道具 4 格 / 场景 9 格，**均须在提示词开头显式写死「共 N 格，不多不少」** |
