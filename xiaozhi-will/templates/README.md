# templates/ 空白项目模板包（开新剧直接复制填）

本目录是**可落盘的空白骨架**：每条都是"填了就能用"的结构，字段编号与路由卡正文引用的章节号严格对齐（如角色包 0.1/0.3/5.3/5.4、场景包 -1~-5/8.2/8.3、道具包 10.2/10.3、分镜"第四章连续性锚点"、机位图 x.1/x.2/x.3），保证 SKILL.md 里"必读捆绑精确到节"的引用在模板上找得到对应位置。

## 一键落盘（推荐）

```bash
# 建目录骨架 + 复制全部模板到对应位置，并批量替换占位符
python scripts/init_project_docs.py "<项目根目录>" \
  --set "新剧名=某某某" --set "第N集=第1集" --set "画幅=16:9" \
  --set "出图模型=seedream_4.5" --set "视频模型=seedance_2.5" --set "帧率=24fps"

# 只预览不写盘
python scripts/init_project_docs.py "<项目根目录>" --dry-run
```

脚本规则：**只新建缺失文件，遇到已存在的文件默认跳过（不覆盖）**，确认要覆盖再加 `--force`。不删除、不移动任何文件。

## 填写顺序（由上到下，别跳）

1. `01` 总索引的 **P0 参数卡**——先把画幅/模型/帧率/时长锁死，后面所有模板的 `【】` 才有值可填（仲裁⑦：参数卡 ＞ 一切外部默认值）。
2. `08` 剧本包（三不：对剧情源不添加/不更改/不删除）→ 剧本定了才有实体可提取。
3. `02/03/04` 三资产包（先出图锁定，**无图不进分镜**）。
4. `06` 机位图 → `05` 分镜表（先空间后镜头）。
5. `07` SOP 前后清单过一遍再投喂。

## 两条硬规矩

- 模板里的 `【方括号】` 全部要换成实际值；**不许用外部 skill 默认值填空**（竖屏 9:16 / R2 高燃 / 21:9 / Higgsfield 模型一律不得覆盖本剧锁定值）。
- 任一 `.md` 改稿后，**立即回填总索引该文件大小（KB）与状态（锁定/缺口/版本 vN）**并保留旧版不覆盖。
