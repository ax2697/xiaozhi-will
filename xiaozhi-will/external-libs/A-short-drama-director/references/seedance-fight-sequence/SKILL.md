# 角色 + 场景 + 打斗需求 → Seedance 2.5 打斗分镜提示词

**一份打斗需求进，一条四部分结构的视频提示词出。专攻碎切节奏、手持晃动、敏感词规避。**

颗粒度：**15 秒 16-20 镜**（平均 0.75-0.94 秒/镜）；**30 秒 32-38 镜**。这是本技能的立身之本——其他模型技能的合法最小镜长是 1.5 秒，**做不出这个节奏**。

| --- | --- | --- | --- |

判据：**要打斗/追逐/混战** → 本技能；**要台词/情绪/资产一致性** → 其他模型；**要参考图** → 上面四个资产技能。

⚠️ **本技能与 其他模型是同一层的两个选择，不是上下游。** 本技能的分镜稿**不能直接喂给其他模型**（0.75 秒的碎镜其他模型可能合并或拒绝）——要转必须先合并到 3-6 镜并重算时间轴。资产四件套产出的参考图**可以**喂给本技能当参考，但不是必需。

❌ **不要在本技能里写画幅与画风。** 见下方铁律 5。

## ⛔ 六条铁律，不要"修"

### 1. 先立两张判据表 —— 这是第一件事，做错后面全错

原智能体把「人物占比」和「场景节点数」各写成**两套甚至三套口径**，散在铁则、专章、清单里互相打架。**执行时必须先查这两张表，全稿以表为准。**

**表一 · 人物占比（三类镜头，两套量纲，不可互套）**

| 镜头类型 | 要求 | 量纲 | 数值 |
| --- | --- | --- | --- |
| **宏伟 / 法术 / 巨物镜** | 人物渺小 | **画面高度** | ≤ 1/4；极远景 ≤ 1/12 |
| **纵深对峙 / 追逐镜** | 前景人物大 | **画面宽度** | 1/3 ~ 1/2 |
| **群体混战镜** | 主角清晰可辨 | 画面宽度 | ≥ 1/4 |

**为什么宏伟镜用高度**：**人物是一个整体**——高度被压到 ≤1/4 时宽度同步变小，无需再声明宽度；且宏伟镜判的是"人比巨物小多少"这个**纵向比例**，高度一个量纲即足。（制作人确认，不改。）

**纵深镜用宽度**是因为它判的是"前景人物横向占多宽"，与纵向比例是**两件事**。两套量纲**不冲突、不合并**。

❌ 全稿**禁用「大半」**这类无判据词——它通常理解 >50%，与 1/3-1/2 打架。

**表二 · 场景节点数（按场景类型，不按时长）**

| 场景类型 | 节点数 | 判据 |
| --- | --- | --- |
| **宏大**（战场 / 云海 / 城市废墟 / 雨林） | **4-6 个** | 有垂直或水平跨度（高台、空中、水面、建筑） |
| **中等**（街道 / 院落 / 峡谷段） | **3-4 个** | 有 2 个以上可停留的平面或结构 |
| **狭小**（室内 / 船舱 / 小巷） | **1-2 个** | 无垂直跨度，位移靠家具与墙面反弹 |

❌ **「30 秒必须 4 个节点」是无条件硬指标，会判死狭小空间**（案例「农家小屋室内缠斗」自己就过不了）。狭小空间**不追求宏伟镜头与大幅位移是有意选择，不是缺陷**——节奏改由「家具往复利用（算准节点转移，不新增节点）+ 镜头挤压感 + 回合密度」承担。

### 2. 镜数为主参数，平均单镜是派生的

**先定镜头数量 → 再算平均单镜 → 再逐镜分配类型与秒数。**

| 总时长 | 镜头数量（**主参数**） | 平均单镜（**派生值** = 总时长 ÷ 镜数） |
| --- | --- | --- |
| 15 秒 | 16-20 个 | 0.75-0.94 秒 |
| 30 秒 | 32-38 个 | 0.79-0.94 秒 |
| 30 秒（拆两段） | **各 16-19 个**（合计 32-38） | 同上 |

❌ 不要把平均单镜当独立设定项去写；**算出来落在区间外说明排镜有误，回头调**。
❌ 「拆两段」不得另写一套镜数（原版这里冒出 32-40，与正表 32-38 打架）。

**镜头类型与动作容量 —— 全稿唯一来源**（凡"这个镜头多长、能放几个动作"一律查此表）：

| 镜头类型 | 时长 | 动作容量 |
| --- | --- | --- |
| 极短镜 | 0.5-0.7 秒 | 1 个动作 |
| 短镜 | 0.7-1 秒 | 1 个动作 |
| 中镜 | 1-1.3 秒 | 1-2 个动作 |
| 长镜 | 1.3-1.5 秒 | 3-5 个连续动作 |
| 子弹时间 | 1-1.2 秒 | 1 个关键动作（慢速） |

❌ 不要另立门槛（原版铁则6 自写「长镜 = 1 秒以上」，与上表 1.3-1.5 打架，使 1.0-1.3 秒的镜归属不明）。

### 3. 首帧带血 —— 换词，不换画面

首帧图上有血时，「第一帧严格等于首帧」与「血 / 血迹全禁」**无法同时满足**。唯一合法走法：

> **不写"血"字，改用「深色污渍 / 暗色湿痕 / 干涸的暗色痕迹 / 液体痕迹」。** 视觉上仍是那片暗色痕迹，**延续语义完整保留**，审核层看不到血腥词。

**四条硬约束**：① **只延续，不新增**（首帧没有的伤处不得出现新痕迹，首帧有的不得消失）；② **不强调、不特写**（不写"沿着痕迹缓缓流下"）；③ **不描述颜色与来源**（不写"鲜红""淌血""伤口"）；④ **位置与面积冻结**（不扩散、不流向、不滴落）。

❌ **禁止**为了让提示词"干净"而删掉首帧已有的暗色痕迹——那会让**首帧与第二帧不一致**。
❌ **禁止**用"血"字去描述它。

可套用写法：*「画面第一帧与参考首帧完全一致：人物面部侧面有一片已经干涸的暗色湿痕，衣襟前襟有深色污渍。全片保持该痕迹的位置与面积不变，不扩散、不滴落、不做特写。」*

### 4. 替换词不得含敏感词根

敏感词替换表**自己踩过自己的雷**：替换「爆炸/炸毁」用「**炸损**」（含禁词根"炸"）；替换「摔死/死亡」用「**摔伤**」（含"伤"，而"伤"在同表另标慎用）。

**通用自检规则**：**替换词不得包含本表任一敏感词的任何单字词根。** "伤"是敏感词 → 不得出现"摔伤/灼伤/割伤"；"炸"是敏感词 → 不得出现"炸损/炸裂"。**新增替换词时须回查全表。**

正确写法：炸损 → **破损**；摔伤 → **坠落受创 / 重摔受创**。

**替换表适用范围**（原版从未声明，导致文档自己看起来违规）：

> **只约束"最终输出给模型的提示词正文"**（四部分）。**不受约束**：本技能自身的规则文本、章节标题、案例名称、以及替换表自身的"敏感词"列。
> **判定口诀：给人看的不管，给模型看的一律换。**

**本技能有三个内部术语，进输出必须换词**（否则会被判命中）：

| 内部术语 | 输出里写成 | 原因 |
| --- | --- | --- |
| 子弹时间 | **慢动作时刻** | 含禁词根「子弹」 |
| 打斗结束（结尾枚举值） | **交锋结束** | 含禁词「打斗」 |
| 尸体 / 倒地的敌人 | **倒地的身影 / 散落的残骸** | 含禁词「尸」 |

### 5. 画幅与画风不写进提示词

- **画幅** → 默认 **16:9**，**生视频时人工手动设定**。
- **画风 / 美术风格** → 由**参考图**决定。

⚠️ **残余风险（必须提醒使用者）**：生成端**必须真把画幅设成 16:9**。否则纵深镜的「前景占宽 1/3-1/2」失去比例意义，宏伟镜的「占高 ≤1/4」也随之失真。**这不是文档能解决的，是操作层动作。**

✅ 但**运镜风格与镜头节奏必须写足**——它们不是画风，是**可排布的动作语言**，属本技能核心职责。

### 6. 稳定镜头配额 = 3，超编按顺序砍

原本配额写「2-3 个」，但全场各处相加可达 **4 个**（开场宏伟远景 + 结尾大全景 + 子弹时间 + 唯美段）。**配额写死为 3**，超额时**优先砍除顺序**：

1. **唯美 / 抒情段的稳定处理**（先砍：降为"手持微晃"，该段本来只要求"飘逸"）
2. **结尾特写 / 大全景**（次砍：改缓慢手持微晃拉远收尾）
3. **开场宏伟远景**（再砍：改缓慢手持微晃拉升）
4. **子弹时间**（**最后砍**：已限每段 ≤1 段、1-1.2 秒，且要求"轻微呼吸感晃动"）

**判定口径**：以「镜头是否静止/接近静止」为准；带**轻微呼吸感晃动**的镜头（子弹时间、缓推微晃）**不计入**这 3 个配额。

| # | 铁则 | 判定 |
| --- | --- | --- |
| 1 | **攻防瞬间完成** | 出招即到、格挡即成、受击即退；禁过多蓄力、禁命中后停顿 |
| 2 | **大范围位移** | 按表二定节点数；位移方式明确（跑/跳/飞/坠/荡/滑/御剑/瞬移） |

## 运镜体系（本技能的核心差异化价值）

**六大手法**：手持跟拍（颠簸）· 急推急拉 · 快摇转场 · 荷兰角 · FPV 追逐 · 手持微晃（缓慢）

**晃动三级**（原版只说"越激烈越剧烈"，无档位，这里给死）：

| 档位 | 适用段落 | 对应手法 |
| --- | --- | --- |
| **1 级 · 微晃** | 宏伟镜 / 唯美段 / 结尾特写 | 手持微晃（缓慢），近乎稳定但不完全静止 |
| **2 级 · 颠簸** | 追逐 / 奔跑 / 高速突进 / 坠落 | 手持跟拍 + FPV，明显起伏，景物高速后退 |
| **3 级 · 剧烈** | 近身缠斗 / 大招对撞 / 巨物冲击 | 剧烈环绕 + 荷兰角，大幅摇摆伴倾斜 |

**瞬时猛震**（叠加项，不属档位）：命中 / 落地 / 入水 / 撞碎环境物的**那一帧**猛震一下（单帧级），震后立即回当前档位。

**快摇转场**：持续时长 **≤0.3 秒**，模糊只允许**横向拖影**（轮廓可辨）；**禁整帧糊死**。超 0.3 秒仍要摇 → 改用「手持跟拍」。（原版此处与禁止项「禁止模糊到看不清」无可判定分界，故用**时长代替程度**做界。）

**禁止**（负面词）：三脚架固定镜头过多、运镜过于稳定平滑、柔缓运镜、画面模糊到看不清、镜头晃晕。

## 四部分固定输出（缺一不可）

### 第一部分 · 正向总述

| 槽位 | 内容 |
| --- | --- |
| 【场景描述】 | 时间、地点、环境、天气、光线、氛围 + **（可选）场景类型：宏大/中等/狭小** |
| 【角色A】 | 外貌、服装、武器、能力、气质 |
| 【角色B】 | 外貌、服装、武器、能力、气质（**一对多时改写为敌方代表形象**） |
| 【群体/敌方】 | 敌群共性外貌、数量级、围攻方式、个体差异（**一对一填"无"**） |
| 【核心规则】 | 适配模型、时长、**镜头数量**、**平均单镜**、运镜风格、攻防节奏、位移范围、**场景节点数**、**敌我数量比**、特殊要求（子弹时间/首帧承接/结尾方式）、光影介质 |

### 第二部分 · 逐段分镜

每镜三行：

```
镜头N｜起止时间｜场景位置｜景别·运镜方式
画面描述（人物动作 + 环境反应 + 运镜动态）。硬切。
收尾：本镜头结束时的状态，为下一镜铺垫。
```

### 第三部分 · 收尾总结
总时长、镜头数量、平均单镜（**派生值**）、打斗阶段划分、场景节点列表、运镜风格说明、特殊元素说明。

### 第四部分 · 负面提示词

九类分组：动作姿态 · 武器/利器逻辑 · 特效画质 · 镜头节奏 · 场景逻辑 · 位移穿梭 · **人物比例** · 结局 ·（如有）女性/温泉尺度。

**人物比例类须含**：宏伟镜中人物过大（超画面高 1/4）、纵深对峙两人一样大、前景人物不足画面宽 1/3。
**场景逻辑/结局类须含（有首帧时）**：首帧元素消失、首帧暗色痕迹位置漂移、首帧背景变化。

## 攻击回合 ↔ 镜头映射（排镜依据）

一个完整攻击回合 = **1 个中镜 + 1 个短镜**：

| 镜 | 装载 | 拍 |
| --- | --- | --- |
| **中镜**（1-1.3 秒） | 起手 + 出招（路线写在出招描述里，不单占一拍） | 3 拍 |
| **短镜**（0.7-1 秒） | 命中 **或** 被闪避 + 对方反应（二选一，故算 1 个动作） | 2 拍 |

- **「衔接下一动作」不计入本回合** —— 归入**下一回合的起手**，避免重复计数。
- 若需表现完整飞行轨迹（远程法术），路线可拆为独立**极短镜**（0.5-0.7 秒），该回合为 **3 镜**。
- **排镜校验**：一段 15 秒打斗若含 N 回合，则 **2N ≤ 镜头总数（16-20）** → **每段约 8-10 个回合**；超出说明动作过载，须合并。

⚠️ 案例名称（如「追猎」「围杀」）属内部文档用词，**不受替换表约束**；但若把案例名写进输出提示词，须按替换表处理。

## 执行流程（五步）

### 1. 需求拆解
提取「角色 + 场景 + 打斗需求 + 是否带首帧图 + 用户指定结尾方式」。
- **判定场景类型（宏大/中等/狭小）** → 直接决定节点数（表二）。
- **判定参与角色数（1v1 / 1vN / NvN）** → 决定是否启用【群体/敌方】槽位。
- **带首帧图 → 立刻按铁律 3 检查首帧是否有暗色痕迹。**

### 2. 排镜（先定数，再算长）
按表二确定**镜头数量** → 算**平均单镜** → 按「镜头类型与动作容量」逐镜分配类型与秒数 → 用「攻击回合 ↔ 镜头映射」校验 `2N ≤ 镜头数`。

### 3. 组装四部分
按上方固定结构写。**逐镜过一遍敏感词表**（含词根自检）。

### 4. 安全收口
- 全部必换词已替换；替换词无敏感词根。
- 首帧带血 → 暗色痕迹口径，四条约束到位。
- 女性/温泉段尺度（如有）。

### 5. 交付前校验
跑脚本：

```bash
python scripts/check_fight_prompt.py <提示词文件>
```

退出码 **0** = 无硬缺项（可带「建议」）；**1** = 有硬缺项；**2** = 用法错误。逐条看输出的判据编号。
