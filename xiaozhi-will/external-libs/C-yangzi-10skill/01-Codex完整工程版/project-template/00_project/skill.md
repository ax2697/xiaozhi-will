# 00_project

项目控制区：由总控维护的项目 Brief、状态、路由与跨阶段参考记忆，是项目推进的核心控制文件集合。

## 本目录文件

- **brief.md**（427B）：项目 Brief 模板，含一句话需求、受众、目标平台、目标时长、内容类型、项目入口（A从零/B完整剧本/C部分资料/D高手镜头优化）、作者剧本是否锁定、视觉方向、目标视频模型（Seedance 2.0 / MiniMax H3 / 双版本 / 未定）、连续性模式、预算限制、不能出现的内容等空字段。
- **project-status.md**（1KB）：项目状态卡（由总控维护），记录项目入口、运行模式、目标阶段、当前状态、用户指定的权威输入、已确认文件、最近产出、跨阶段参考记忆路径、知识库外挂状态、作者剧本锁定、生产资料状态、视频模型、镜头规划状态、连续性模式，并附维护规则（一次一个 Skill、不改已确认内容、08 先确认镜头规划等）。
- **reference-memory.md**（3KB）：本地知识库跨阶段参考记忆模板。定义权威顺序（用户本轮要求 > 最新已确认项目文件 > 启用参考方法 > 模型通用知识）、使用规则、稳定编号"参考方法001…"、使用范围（故事创作 01-05 / 图像资产 06 / 表演 07 / 视频镜头 08 / 全流程 01-08 / 指定阶段）、已确认参考条目字段、参考变更记录与阶段应用记录。
- **routing.md**（2KB）：当前路由（由总控维护）。记录运行模式、项目入口、当前阶段、当前唯一输出、知识桥状态、本阶段启用参考、建议下一步等，并列出 A/B/C/D 可选入口与路由原则（一次一个 Skill、可切换回退、知识桥默认不提示、权威顺序等）。
- **_索引.md**：本目录索引，列出以上四个文件。
