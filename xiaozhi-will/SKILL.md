# AI「指令 → 文件」路由卡（万能模板版 · 新短剧开拍通用）

来源：《_AI指令文件路由卡_万能模板_新短剧用(1).html》——**工作流 ＋ 方法论骨架，已剥离任何单剧剧本内容**。原版 HTML 备份在 `references/route-card-full-source.html`。

**本技能不是一份读物，是一条存取约定**：指令进来先在本卡取齐"读哪些文件的哪一节"，再去读项目文件。不要凭对话记忆动手。

## 一、触发场景

- 用户在短剧 / 漫剧项目里下达任何制作指令
- 用户说「按路由卡执行」「第 N 集开工」「新剧立项」
- 需要判定"两个文件冲突时听谁""上游改了要回改谁"

## 二、六步固定响应流程

| 步 | 动作 | 要点 |
|---|---|---|
| **0** | 先 Read 磁盘最新稿 | 磁盘当前文件为准，旧记忆 / 摘要一律过期 |
| **1** | 解析指令 | 动作 ＋ 对象 ＋ 产物类型 |
| **2** | 方法论先行 | 按产物类型先读 references 命中章节 |
| **3** | 再读总索引 | 参数卡 · 最新状态 · 双编号 · 定稿门禁 |
| **4** | 第一依据 ＋ 捆绑取齐到节 | 路由表第一依据 ＋ SOP ＋ 前缀负向逐字复制 |
| **5** | 执行 · 双自检 · 归位 | SOP 核验 ＋ 方法论自检 ＋ 下游联动 ＋ 报用户确认 |

## 三、指令 → 文件 路由总表

| 指令 | 第一依据 | 必读捆绑（精确到节） | 产出归位 |
|---|---|---|---|
| 生成**角色** | 角色包 · 该角色 x.1 | SOP；0.1~0.3 / 5.3 门禁；x.2~x.5 | `资产图片音频汇总/角色设定图/{角色}/` |
| 生成**场景** | 场景包 · 该 S 分节 | SOP；六视图 / 光影 / 空间锚点；机位图轴线 | `资产图片音频汇总/场景设计图/` |
| 生成**道具** | 道具包 · 该 P 分节 | SOP；六视图 / 材质 / 陈设；场景承托面 | `资产图片音频汇总/道具设计图/{道具}/` |
| 生成**关键帧** | 10 字段分镜 · 该镜 | 连续性锚点；关键帧公式；机位图站位 | `资产图片音频汇总/关键帧/` |
| 生成**视频片段** | 10 字段分镜 · 逐镜 | SOP 三；剪辑包闸门；P4 投喂六步 | `资产图片音频汇总/视频片段/` |
| 改剧情 / 台词 / 人设 | 项目剧本包 | 本集剧本分场；剧情源 | 更新 `.md` 重生成 docx |
| 切镜头 / 改机位 | 10 字段分镜 | 模板库 7.2~7.4 / 6.4 轴线 | 同步机位图 |
| 剪辑 / 转场 / 配乐 | 剪辑资产包 | 剪辑包 7 九步 SOP / 10 质检 | 母版出 16:9 |
| 查原著依据 | 第十章查章路由 | 剧情源结构地图 | — |

## 四、机位图四类必读时机

**必读**：① 场景六视图；② 关键帧站位；③ 视频片段（守 180°轴线）；④ 道具放回场景 / 改镜头 / 剪辑。
**不需读**：纯角色 / 纯道具的白底单品图。
**空间权威口径**：场景布局 / 画左画右 / 轴线以**机位图最高**。

## 五、出「关键帧」专用取件清单

- **分镜**：该镜 10 字段 ＋ 第四章连续性锚点
- **角色关键帧**：角色包 5.4 公式 ＋ 0.4 用法 ＋ x.6 基底
- **场景关键帧**：场景包 8.3 公式 ＋ -2 光影 -3 空间锚点
- **道具关键帧**：道具包 10.3 公式 ＋ -3 空间锚点 -5 叙事陈设

## 六、改动联动

| 你改了什么 | 必须回头同步谁 |
|---|---|
| 剧本 / 台词 / 情节 | 分镜 → 机位图 → 三包 → 情绪曲线 |
| 分镜镜头号 / 机位 | 机位图 x.2 部署表、分镜第四章锚点 |
| 场景坐标 / 轴线 | 机位图、场景包该 S、已出场景图 |
| 角色锚点 / 基准脸 | 重锁基准脸、角色包、已出设定图 |
| 固定前缀 / 负向 | 以资产包原文 ＋ 总索引参数卡为准 |

## 七、冲突仲裁优先级

⓪ 磁盘当前 `.md` ＞ 对话记忆　① `.md` ＞ `.docx`　② 10 字段分镜 ＞ 基础分镜　③ 资产包原文 ＋ 参数卡 ＞ SOP　④ 双编号查映射表　⑤ 最新拍板日期优先　⑥ 门禁不跳级、剧情三不　⑦ **本集 `.md` ＞ 外部 skill 方法论**　⑧ **剧情源原文 ＞ 总纲 ＞ 分集大纲 / 剧本 / 分镜**

## 八、交付前防遗漏自检

- 磁盘最新稿已 Read、未凭记忆动手
- 方法论先行：动手前已读完命中的 A/B/C 库章节
- 涉空间 / 站位 / 机位，已读机位图并核画左画右
- 关键帧取了分镜连续性锚点 ＋ 三包公式
- 下游联动已全部同步
- 生成后**真打开用眼睛看**、真 PNG / 原生尺寸 / 不插值
- **未用 skill 默认值**覆盖本剧锁定值
- 凡动剧情，已逐项核对做到**不添加 / 不更改 / 不删除**
