# 04 · 交付格式与自检

> 本文件是**交付说明书**：四部分的完整模板、21 项交付前校验清单、脚本判据表、常见失败与修法、以及与 其他模型的衔接。

---

## 一、四部分输出（缺一不可）

### 第一部分 · 正向总述

| 槽位 | 填写要求 |
| --- | --- |
| 【场景描述】 | 时间、地点、环境、天气、光线、氛围 + **（可选）场景类型：宏大 / 中等 / 狭小** |
| 【角色A】 | 外貌、服装、武器、能力、气质 |
| 【角色B】 | 外貌、服装、武器、能力、气质（**一对多时改写为敌方代表形象**） |
| 【群体/敌方】 | 敌群共性外貌、数量级、围攻方式、个体差异（**一对一填"无"**） |
| 【核心规则】 | 适配模型、**时长**、**镜头数量**、**平均单镜**、运镜风格、攻防节奏、位移范围、**场景节点数**、**敌我数量比**、特殊要求（子弹时间 / 首帧承接 / 结尾方式）、光影介质 |

**原版两处缺项，本技能补**：

1. **模板缺【群体/敌方】槽位** —— 但五章有「群体混战规范」、案例有「千军围杀」，第三方**无处落笔**。补槽位 + 补【敌我数量比】。
2. **【核心规则】缺镜头数量与节点数** —— 原列了七项却**没有**这两项，而它们恰是时长表与节点分档的强约束，不写进总述就无法在成片端核对。补「镜头数量」「平均单镜」「场景节点数」。

### 第二部分 · 逐段分镜

**每镜三行，格式固定**：

```
镜头N｜起止时间｜场景位置｜景别·运镜方式
画面描述（人物动作 + 环境反应 + 运镜动态）。硬切。
收尾：本镜头结束时的状态，为下一镜铺垫。
```

- **起止时间**建议格式：`00:00.00-00:00.90`（分:秒.厘秒）
- **「硬切」**写在画面描述末尾，标明与下一镜的连接方式。
- **收尾行**必须写——它承担"为下一镜铺垫"，也是铁则5「动作来龙去脉」的落点。

### 第三部分 · 收尾总结

- 总时长、**镜头数量**、**平均单镜（派生值）**
- 打斗阶段划分（如：开场交锋 → 坠落 → 穿越 → 高潮 → 收尾）
- **场景节点列表**
- 运镜风格说明
- 特殊元素说明（子弹时间 / 宏伟镜头 / 首帧承接 / 结尾方式）
- **攻击回合数与排镜校验**（2N ≤ 镜头数）

⚠️ 「平均单镜」是**派生值**（= 总时长 ÷ 镜头数量），**不是独立设定项**。须先写总时长与镜数，平均单镜由二者算出；**算出的值落在区间外说明排镜有误，回头调**。

### 第四部分 · 负面提示词

**九类分组**：

1. 动作姿态类
2. 武器 / 利器逻辑类
3. 特效画质类
4. 镜头节奏类
5. 场景逻辑类
6. 位移穿梭类
7. **人物比例类**
8. 结局类
9. （如有）女性 / 温泉尺度类

**必须补进去的两组**（原版没有）：

| 类 | 补充负面 |
| --- | --- |
| **人物比例类** | 宏伟镜中人物过大（超过画面高度 1/4）；纵深对峙两人一样大；前景人物不足画面宽度 1/3 |
| **场景逻辑 / 结局类**（**有首帧时必加**） | 首帧元素消失；首帧暗色痕迹位置漂移；首帧背景变化；首帧人物换装 |

⚠️ **负面词同样受替换表约束**（它也是给模型看的文本）。写负面时避开"血 / 死 / 伤 / 战"等词——用描述性写法，例：不写「无血腥元素」，写「新增伤处」→ 改为「痕迹扩散」。**"给人看的不管，给模型看的一律换"**同样适用。

## 二、21 项交付前校验清单

### A. 结构与槽位（H1-H5）

- [ ] **H1** 四部分齐全：正向总述 / 逐段分镜 / 收尾总结 / 负面提示词
- [ ] **H2** 【场景描述】在，且标注了场景类型（宏大 / 中等 / 狭小）

- [ ] **H4** 【角色B】在
- [ ] **H5** 【核心规则】在

### B. 核心规则必含项（H6-H11）

- [ ] **H6** 【核心规则】含「时长」
- [ ] **H7** 【核心规则】含「镜头数量」
- [ ] **H8** 【核心规则】含「平均单镜」
- [ ] **H9** 【核心规则】含「场景节点数」
- [ ] **H10** 【核心规则】含「结尾方式」（取值须是三类之一）
- [ ] **H11** **群体场景**（千军/围攻/混战）必须启用【群体/敌方】+ 写明【敌我数量比】

### C. 排镜数字（H12-H15）

- [ ] **H12** 分镜用统一镜次格式（`镜头N｜起止时间｜场景位置｜景别·运镜方式`），至少 4 镜
- [ ] **H13** **每镜都有起止时间**（不得有无时间的镜）
- [ ] **H14** 每镜时长落在 **0.5-1.5 秒**（子弹时间 1-1.2 秒）
- [ ] **H15** 声明的「镜头数量」与**实际镜头数一致**；平均单镜（= 时长 ÷ 镜数）落在 **0.75-0.95 秒**
- [ ] **H20** 场景节点数**与场景类型匹配**（宏大 4-6 / 中等 3-4 / 狭小 1-2）

### D. 安全（H16-H19）

- [ ] **H16** **必换敏感词零命中**（血 / 死 / 战争 / 战斗 / 打斗 / 子弹 / 枪 / 爆炸 / 尸 / 自杀 / 开火 / 射击 / 扫射 / 追猎 / 猎杀 / 机炮 / 火炮 / 导弹 / 火箭弹 / 击中等）
- [ ] **H17** **敏感词根组合零命中**（炸损 / 炸裂 / 摔伤 / 灼伤 / 割伤）
- [ ] **H18** 无「大半」这类无判据词
- [ ] **H19** 首帧承接：出现「首帧」时**不得出现"血"**，描述痕迹须用「深色污渍 / 暗色湿痕 / 干涸的暗色痕迹」

### E. 内容质量（H21 + W 系列）

- [ ] **H21** 收尾总结含：总时长 / 镜头数量 / 平均单镜 / 场景节点列表
- [ ] **W1** 稳定镜头 ≤3 个（超额按 `01` 的砍除顺序裁决）
- [ ] **W2** 出现了晃动描述（手持 / 晃动 / 颠簸 / 荷兰角）
- [ ] **W3** 子弹时间 ≤1 段
- [ ] **W4** 快摇转场标了时长（≤0.3 秒）
- [ ] **W5** 出现攻击回合映射说明（1 中镜 + 1 短镜）
- [ ] **W6** 【核心规则】未写画幅 / 画风（写了要删——由生成端与参考图决定）

## 三、脚本判据表

```bash
python scripts/check_fight_prompt.py <提示词文件>
```

| 退出码 | 含义 |
| --- | --- |
| **0** | 无硬缺项（可带「建议」行） |
| **1** | 有硬缺项，逐条列出判据编号 |
| **2** | 用法错误（文件不存在 / 未传参） |

判据编号与上表一一对应。**H 系列是硬判**，**W 系列是建议**。

⚠️ **本脚本用于校验「输出的提示词文本」，不适用于校验智能体源文档。** 源文档里的替换表**必然**含敏感词列（要写出被禁词才能做对照），拿它去跑必然满屏报错——那是正常的，不是问题。**要校验的是本技能产出的四部分提示词。**

⚠️ 脚本判据编号说明：清单正文用 H1-H21 顺序编号，脚本实现里把「负面提示词分类齐」独立为 **H22**（对应清单 E 组），把原 H20（节点匹配）保留为 **H20**。**以脚本输出的编号 + 文字描述为准**。

## 四、常见失败与修法

| 症状 | 根因 | 修法 |
| --- | --- | --- |
| 脚本报 H15「镜数不符」 | 中途增删了镜头，忘了回头改【核心规则】 | 改镜数后**同步**改核心规则的「镜头数量」与「平均单镜」 |
| 脚本报 H16 命中敏感词 | 分镜描述里写了"血""爆炸""打斗" | 按 `03` 的表逐处替换；**替换后回查词根**（H17） |
| 脚本报 H14「镜长超界」 | 把 1.8 秒的镜写成"长镜" | 长镜上限 1.5 秒；更长要拆成两镜 |
| 脚本报 H11 | 写了"千军围攻"却没启用群体槽位 | 补【群体/敌方】+【敌我数量比】；【角色B】改为敌方代表 |
| 脚本报 H19 | 首帧描述里出现"血" | 换「深色污渍 / 暗色湿痕」；四条约束到位 |
| 脚本报 H20 | 狭小空间写了 4 个节点 | 改 1-2 节点；节奏改由家具往复 + 镜头挤压 + 回合密度承担 |
| **稳定镜头数 4** | 开场远景 + 结尾大全景 + 子弹时间 + 唯美段都做成稳定 | 按 `01` 顺序砍：唯美段 → 结尾大全景 → 开场远景 → 子弹时间最后砍 |
| 平均单镜算不回区间 | 先定了平均单镜再凑镜数 | **反过来做**：先定镜数，再算平均 |
| 案例名进输出带了敏感词 | 「追猎」「围杀」写进了提示词 | 换成「追逐」「交锋」 |
| 脚本报 H16 命中「子弹」 | 把内部术语「子弹时间」写进了输出 | 输出里写「**慢动作时刻**」（见 `03`） |
| 脚本报 H17 命中「炸裂/炸开」 | 描述破坏时用了带「炸」的组合词 | 换「崩开」「破裂」「碎裂」 |

## 五、碎切节奏与适用边界

本技能（Seedance 2.5 打斗）的核心是**碎切节奏**：

- 单镜时长 0.5-1.5 秒（碎切为主），15 秒 16-20 镜、30 秒 32-38 镜。
- 输出结构为四部分（正向总述 + 逐段分镜 + 收尾总结 + 负面提示词）。
- 角色一致性靠纯文本描述 + 受伤状态延续；如有上游资产图，可作为参考素材绑定。
- 强项：打斗节奏、运镜、敏感词规避。
- 运镜三原则（稳定镜头 ≤3 / 越激烈越晃 / 唯美段飘逸）。

**适用边界**：本技能专为打斗 / 追逐 / 混战场面设计。情绪 / 台词 / 资产一致性要求高的文戏场面，走晓之奥义主流程 P3 分镜。晓之奥义只允许 Seedance 2.5 与万相3.0，不使用 MiniMax H3 等其他模型。

## 六、交付时要说给使用者听的两句话

1. ⚠️ **生成端必须把画幅设成 16:9** —— 否则「前景占宽 1/3-1/2」与「宏伟镜占高 ≤1/4」的比例判据会失真。这是操作层动作，提示词解决不了。
2. 📌 **画风由参考图决定** —— 本技能不声明画风；要某种美术风格，就喂对应的参考图。
