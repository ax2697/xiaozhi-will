# 【新剧名】· 图片视频生成执行规范 SOP

> 用法：第 5 步"执行·双自检"时过本文。**生成前清单**缺一项不得调用工具；**生成后清单**缺一项不得交付。
> 冲突时：Seedance/SeedAudio 官方硬约束 ＞ 本 SOP ＞ 外部方法论（详见 `references/09D-*`）。

- 画幅：【画幅】　出图模型：【出图模型】　视频模型：【视频模型】　帧率：【帧率】
- 版本：v1　建立日期：【YYYY-MM-DD】

## 一、静态流水线（出图：角色 / 场景 / 道具 / 关键帧）

1. 读第一依据（对应资产包该分节）＋ 0.1 基底 / 0.2 负向（**逐字复制**）。
2. 取已锁参考图（基准脸 / 场景图 / 道具图），确认"无图不进分镜"。
3. 组 prompt：身份/空间写密，装饰形容词删光；≤1500–2000 字符；正向 ＞ 负向。
4. 过生成前清单（第四节）→ 出图。
5. 过生成后清单（第五节）→ 命名归位 → 回写总索引状态。

## 二、改图流水线

- 固定次序：**NBP → 材质 pass → 局部微改**，一次只改一处。
- 编辑＝最小 CHANGE ＋ 穷尽 PRESERVE EXACTLY；旧版保留不覆盖。
- 改图后若涉及形象锚点，回角色包 x.5 与已锁基准脸。

## 三、视频流水线（P4 投喂，每段≤15s）

1. **模板与时长预算**：组数＝成片秒数÷12~15s；每组≤15s、3~4 镜、单镜 3~5s（高动态微步进 0.5~1s）；每组自带从 00:00 的完整时间轴 / 画幅 / @资产 / 负向。
2. **画幅路由**：顶部声明【画幅】，每条回填锁定值，零回落竖屏。
3. **镜头规格**：五要素 [景别·视角角度·运镜·跟随目标]；中全景禁 90° 正拍，用 30~60° 斜角；相邻镜景别阶梯跃迁、同运镜 ≤2s。
4. **对白三查**（有对白必过）：台词时长 ≤ 镜预算（超时 P0 拆镜，单句 >24 字拆）；金句后留 0.3~0.8s 反应镜；语速卡是内部 QC，不入投喂正文。
5. **战斗档二选一不混用**：R3 玄幻 / 武侠现代；Seedance 2.5 标 Hit-Stop 0.1s 与 `[SFX:]`。
6. **出稿质检**：P0（时长/台词/跳轴/画幅/@锚点）→ P1（受力/节奏/光源）→ P2（无空镜/反形容词/声音电平）。

### 投喂前 7 项自检（Seedance 2.5，缺一不得调用）

| # | 检查 | 通过 |
|---|---|---|
| 1 | `model_version` 精确等于 `seedance_2.5` | ☐ |
| 2 | prompt 与用户确认原文**逐字一致**（未扩写/润色/翻译/重排） | ☐ |
| 3 | 时长为 5~30 整数秒，单组 ≤15s | ☐ |
| 4 | 比例属于 16:9/4:3/1:1/3:4/9:16/21:9（本剧＝【画幅】） | ☐ |
| 5 | 已向用户展示完整确认信息并获**明确确认**（沉默/模糊不算） | ☐ |
| 6 | 时长/比例/参考素材均获确认，其他信息位于独立工具参数中 | ☐ |
| 7 | 参考图走独立输入，未写进 prompt | ☐ |

## 四、生成前清单（通用）

- [ ] 磁盘最新稿已 Read（第 0 步）；第一依据读对；必读捆绑精确到节
- [ ] 方法论已先行加载（第 2 步），检查清单在手而非做完才补
- [ ] 涉空间/站位/机位/轴线 → 已读机位图并核画左画右
- [ ] 关键帧 → 已取分镜第四章连续性锚点 ＋ 三包关键帧公式
- [ ] 固定前缀 / 负向逐字复制；画幅、模型为本项目锁定值
- [ ] 下游联动已确认（改了上游就要同步谁）

## 五、生成后清单（通用）

- [ ] **真打开用眼睛看**（视频真看片、图片真 PNG 原生尺寸不插值）
- [ ] 三库自检：LIRA pre-send / CINEDANCE 静默 QA 20 问 / ACTING 0–5 量表 **≥4**
- [ ] P0 清零；P1 逐条修复或标注接受；P2 建议优化
- [ ] 声音三层电平：对白 0dB ＞ 音效 -6dB ＞ BGM -14dB
- [ ] 命名归位正确；旧版保留不覆盖；**总索引状态与文件大小已回写**
- [ ] 已报用户确认

## 六、P0 / P1 / P2 判定口径

| 级别 | 内容 | 处置 |
|---|---|---|
| **P0** | 时长超预算 / 台词超时 / 跳轴 / 画幅错 / @锚点指向未锁图 / 模型不符 / prompt 被改写 | 阻断返工 |
| **P1** | 受力不对 / 节奏拖沓 / 光源矛盾 / 生成前未确认 | 修复或明确标注接受 |
| **P2** | 空镜 / 形容词堆砌 / 声音电平不理想 / 质感偏差 | 优化建议 |

## 七、音频（SeedAudio 1.0）投喂口径

- 出现参考音频指代（`音频1`／「参考音频1」／「附件1」／文件名）→ **A2A**；无 → **T2A**。
- 归一化：按首次出现顺序编为 `@音频1/@音频2/@音频3`（≤3 条），URL 进 `audio_reference_url_list`，**不写进 prompt**。
- 复杂场景**整段一次调用**，不按角色拆分拼接。
- 台词（人声对白）永远走声音层单独生成，**不写进画面提示词当口型**。
- `duration` 仅在用户明确指定秒数时才传。

## 八、禁止事项速查

- 不用外部默认值覆盖本剧锁定值（9:16 / 21:9 / R2 高燃 / Higgsfield / Seedance 2.0）。
- 不把参考图 URL、文件名、场号、写作笔记写进 prompt。
- 不用"上一镜头 / as before / continues"等省略式连续性词（每条提示词须独立可懂）。
- 不跳门禁、不覆盖旧版、不凭记忆动手。
