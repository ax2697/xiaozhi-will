# 26 · 道教全体系总纲（不止内丹）

> **本文做什么**：把道教**八大分支**全部接入我们的生产体系，每个分支解决一类具体问题。
> **前提**：内丹只是道教的一支。只用内丹，等于只用了道教的一成。

---

## 〇 · 为什么不能只用内丹

内丹讲「炼」，管的是**从无到有**的过程。

但一部片子从想法到成片，要过的远不止"炼"这一件事：

| 你会遇到的问题 | 内丹能解吗 | 该找哪一支 |
|:---|:--:|:---|
| 该做什么题材？什么该拍什么不该拍 | ❌ | **道教戒律**（有所不为） |
| 两条路都能走，选哪条 | ❌ | **易学·卜筮**（决疑） |
| 片子怎么排布才顺 | ⚠️ 部分 | **风水堪舆**（形势布局） |
| 什么时候发、发给谁 | ❌ | **择日·星命**（择时择人） |
| 团队怎么建、怎么带 | ❌ | **道教组织**（宫观制度） |
| 画面怎么有仙气 | ⚠️ 部分 | **符箓·科仪**（视觉符号） |
| 内容会不会触雷 | ❌ | **戒律·积善**（合规底线） |
| 做久了怎么不退转 | ✅ 部分 | **丹道**（含炼己） |
| 怎么解释"为什么这么拍" | ❌ | **老庄哲学**（道法自然） |

> **一句话**：**内丹管"怎么炼"，其余七支管"炼什么、什么时候炼、跟谁炼、炼到什么程度停"。**

## 二 · ① 道家哲学：一切判据的根

### 核心三句

| 句 | 出处 | 用在生产哪里 |
|:---|:---|:---|
| **道法自然** | 《道德经》二十五章 | **不硬掰**。角色该这样就这样，不为爽而改人设 |
| **无为而无不为** | 《道德经》三十七章 | **不越权**。AI 不替用户做决定，只把选项摆清 |
| **反者道之动** | 《道德经》四十章 | **反转的哲学根据**。剧情反转不是技巧，是道的运动方式 |

### 三句落地判据

> 这三句不是口号，是**能判违规的**。命中「违规」列任一项，就是没做到。

| 判据 | 怎么做 | **违规**（命中即没做到） |
|:---|:---|:---|
| **道法自然** | 写角色时先问：这个人**本来会怎么做**？不是"怎么写更爽" | 为了爽点让角色**做出违背前文人设**的选择，且没给转变铺垫 → 违规 |
| **无为** | AI 只做用户明确要的。**没说的，不替他定** | 用户没说的参数（画幅/时长/比例/风格），AI **自己填了默认值** → 违规 |
| **反者道之动** | 每场戏找一个"反"——**观众以为 A，你给 B** | 整场戏**观众能提前猜到结局**，没有任何反转或意外 → 违规（钩子失效） |

> **判据的用法**：写完一场戏，拿这三行逐条问。
> 「这角色为什么这么做，前文交代过吗」「这个参数是用户说的还是我填的」「观众猜得到吗」——**三问答不上来，就是没做到**。

### 庄子的三个用法

| 篇 | 概念 | 用在生产哪里 |
|:---|:---|:---|
| **齐物论** | 彼亦一是非，此亦一是非 | **多视角叙事**。同一件事，不同角色的版本不同 |
| **逍遥游** | 无用之用 | **留白与闲笔**。不是每镜都要推剧情 |
| **养生主** | 庖丁解牛，依乎天理 | **顺着结构切**。剪辑点顺着动作与语义，不硬切 |

## 三 · ③ 易学卜筮：决策与分支

### 为什么这算道教

八卦、六十四卦是道教核心符号体系（《周易》为道教"三玄"之一）。**不是算命，是一套决策框架。**

### 三个落地用法

#### 用法一 · 阴阳定基调

| 卦象 | 用在生产 |
|:---|:---|
| **纯阳（乾）** | 阳刚、外放、动作戏、爽点 |
| **纯阴（坤）** | 阴柔、内敛、情感戏、虐点 |
| **阴阳交错** | 张力场。**最好的戏都在交错处** |

> **判据**：一场戏如果"全是阳"或"全是阴"，就平了。**要找交错点。**

#### 用法二 · 六爻定节奏

一卦六爻，正好对应**六段结构**：

```
初爻 → 起（铺垫）
二爻 → 承（发展）
三爻 → 转（第一次转折）
四爻 → 再转（第二次转折）
五爻 → 高潮
上爻 → 收（余韵）
```

> **这是短剧六段的原型。** 不是巧合——**叙事结构与卦象结构同源**。

#### 用法三 · 变卦定分支

互动剧的分支设计，可用「**本卦 → 变卦**」：

| 概念 | 用在生产 |
|:---|:---|
| **本卦** | 当前剧情状态 |
| **动爻** | 关键抉择点 |
| **变卦** | 抉择后的走向 |

> **一条动爻 = 一个分支点。** 动爻越多，分支越多——但**动爻超过两处，观众就记不住了**。

### 明确边界

> ⛔ **不搞算命、不搞吉凶预测、不搞占卜决策**。
> 这里只借用**结构框架**（阴阳 / 六爻 / 变卦），用于叙事设计。

## 四 · ④ 风水堪舆：空间与形势

### 为什么这算道教

堪舆（风水）是道教五术之一（山、医、命、相、卜中的"相"）。**核心是"形势"——空间如何影响人的感受。**

### 三个落地用法

#### 用法一 · 藏风聚气 = 画面张力

| 概念 | 用在生产 |
|:---|:---|
| **藏风** | 画面要有遮挡。全开阔 = 无张力 |
| **聚气** | 视觉重心要聚。散 = 观众眼睛无处落 |
| **界水** | 用横向元素（水、路、桌）分隔前后景 |

> **判据**：一个画面如果"什么都看得见"，就没有张力。**必须有遮挡、有纵深、有界限。**

#### 用法二 · 四象定位 = 机位方位

| 四象 | 方位 | 用在机位 |
|:---|:---|:---|
| **青龙** | 左 | 主场。主角常在此侧 |
| **白虎** | 右 | 客位。对手 / 冲突方常在此侧 |
| **朱雀** | 前 | 明堂。开阔面，机位常在此 |
| **玄武** | 后 | 靠山。背景墙 / 山体 / 建筑 |

> **这不是迷信，是构图惯例**：人从左往右读图，左侧天然"主"，右侧天然"客"。
> **风水说的，和视觉心理学说的，是同一件事。**

#### 用法三 · 形势 vs 理气

| 派 | 关注 | 用在生产 |
|:---|:---|:---|
| **形势派** | 山形水势、大局 | **大场景布局**：这片地什么形状、什么走向 |
| **理气派** | 方位、气场 | **小空间调度**：这个房间门窗在哪、光从哪来 |

> **大景看形势，小景看理气。** 两个都要，不分高下。

## 五 · ⑤ 符箓科仪：视觉符号与仪式

### 为什么这算道教

符箓是道教最独特的视觉语言。**科仪是仪式流程——仪式感就是节奏感。**

### 三个落地用法

#### 用法一 · 符的结构 = 视觉层次

| 符的部位 | 用在画面 |
|:---|:---|
| **符头** | 画面顶部（天空 / 匾额 / 光） |
| **符胆** | 画面中心（主体 / 焦点） |
| **符脚** | 画面底部（地面 / 前景 / 阴影） |

> **判据**：三层都清楚，画面就"立得住"。缺一层，画面就飘。

#### 用法二 · 科仪的节奏 = 场面调度

道教法事有固定节奏：**请神 → 上香 → 诵经 → 送神**。

| 科仪段 | 用在场面调度 |
|:---|:---|
| **请神** | 起势。人物登场 / 环境交代 |
| **上香** | 聚焦。核心动作开始 |
| **诵经** | 主体。冲突 / 情感展开 |
| **送神** | 收势。人物离场 / 余韵 |

> **四段一场戏。** 少了"请"和"送"，戏就是"半截"的。

#### 用法三 · 罡步 = 走位路径

道教"步罡踏斗"有固定步法（如"三步九迹"）。

| 步法 | 用在走位 |
|:---|:---|
| **直线** | 决断、冲突 |
| **弧线** | 迂回、试探 |
| **折返** | 犹豫、回头 |
| **环绕** | 包围、压迫 |

> **走位不是随便走。** 每种走法有固定的情绪含义。

## 六 · ⑥ 戒律积善：合规底线

### 为什么这算道教

道教有完整的戒律体系：**五戒、十善、初真十戒、中极三百戒、天仙大戒**。

**戒律不是限制，是"什么不许做"的清单**——这正是合规需要的。

### 五戒对应内容红线

| 戒 | 原义 | 用在内容 |
|:--:|:---|:---|
| **一戒杀生** | 不害众生 | ⛔ 不美化暴力、不炫血腥 |
| **二戒偷盗** | 不取非分 | ⛔ 不抄袭、不盗用 IP |
| **三戒邪淫** | 不犯非礼 | ⛔ 不涉色情、不物化 |
| **四戒妄语** | 不欺诳 | ⛔ 不虚假宣传、不误导 |
| **五戒酒肉** | 不乱心性 | ⚠️ 慎用成瘾物、赌博元素 |

> **这五条正好覆盖内容合规的主要红线。** 不是巧合——**戒律本来就是为了"不伤害人"。**

### 十善的正面清单

| 善 | 用在内容 |
|:--|:---|
| 不杀 · 不盗 · 不淫 · 不妄语 · 不两舌 · 不恶口 · 不绮语 · 不贪 · 不嗔 · 不痴 | 反过来就是**正向价值**：尊重生命、诚实、和合、善语、节制、平和、明理 |

> **判据**：一部片子如果"十善"一条都不沾，价值导向就有问题。

### 明确边界

> 我们是**借用戒律作为内容合规的自检框架**，不涉及宗教教义评判。
> 不做"是否符合教义"的判定，只做"是否伤害受众"的判定。

## 七 · ⑦ 择日星命：时机与受众

### 为什么这算道教

择日（黄历）、二十八宿、十二建除，是道教"五术"中的"命"与"卜"。

### 两个落地用法（去迷信化）

#### 用法一 · 十二建除 = 发布节奏

十二建除：**建、除、满、平、定、执、破、危、成、收、开、闭**。

去掉吉凶，只留**节奏含义**：

| 建除 | 节奏含义 | 用在发布 |
|:--:|:---|:---|
| **建** | 起 | 首集 / 开播 |
| **除** | 去旧 | 转折集 / 清旧账 |
| **满** | 满 | 高潮集 |
| **平** | 平 | 过渡集 |
| **定** | 定 | 定局集 |
| **执** | 持 | 僵持集 |
| **破** | 破 | 破裂集 / 大转折 |
| **危** | 危 | 危机集 |
| **成** | 成 | 收束集 |
| **收** | 收 | 回收伏笔 |
| **开** | 开 | 新局 / 新篇 |
| **闭** | 闭 | 季终 / 结局 |

> **判据**：一季的十二集，如果**全是"满"和"破"**，观众会累。
> **必须有"平"和"定"来呼吸。**

#### 用法二 · 二十八宿 = 受众分层

二十八宿分四象七宿。去掉星占，只留**分层框架**：

| 象 | 气质 | 对应受众 |
|:--|:---|:---|
| **东方青龙** | 生发、向上 | 年轻向、成长向 |
| **南方朱雀** | 明亮、外放 | 大众向、爽点向 |
| **西方白虎** | 肃杀、决断 | 硬核向、动作向 |
| **北方玄武** | 沉潜、隐秘 | 深度向、悬疑向 |

> **一部剧只能主打一象。** 主打两象，两头不靠。

### 明确边界

> ⛔ **不做吉凶预测、不测运势、不承诺"选这天必爆"**。
> 只借**节奏框架**与**受众分层框架**。

## 八 · ⑧ 宫观制度：团队与分工

### 为什么这算道教

道教宫观有严密的**丛林制度**：方丈、监院、知客、知库、知殿……**各司其职，不越位。**

### 三都五主十八头 → 团队分工

| 道职 | 原职责 | 用在团队 |
|:---|:---|:---|
| **方丈** | 一观之主，传法 | 项目总负责人 / 导演 |
| **监院** | 总管事务 | 制片 / 项目经理 |
| **知客** | 接待外客 | 对外沟通 |
| **知库** | 管库房 | 资产管理员（资产包归他） |
| **知殿** | 管殿堂 | 场景负责人 |
| **知翰** | 管文书 | 剧本 / 文档负责人 |
| **知随** | 随侍 | 助理 |

> **落地判据**：一个项目，如果**「谁知道资产在哪」答不上来**，就是缺"知库"。

### 丛林三原则 → 协作纪律

| 原则 | 原义 | 用在协作 |
|:---|:---|:---|
| **一日不作，一日不食** | 不劳不食 | **不产出不占位**。不干活的角色删掉 |
| **普请** | 全体共作 | **大节点全员对齐**（不是各干各的） |
| **清规** | 违者罚 | **返工要有账**。谁改坏了，谁修 |
