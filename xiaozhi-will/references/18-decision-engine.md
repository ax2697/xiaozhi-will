# 18 · 炼气阶 · 选型依据（情境映射 E01–E15）

> **归位**：四阶 · 炼气（P3 分镜）· 解决「这场戏该用什么镜头」
> **来源**：漫剧老李 V7.4.26 `sd-decision-engine`（MIT），本文为道教化重整与精简版。完整原文见 `external-libs/D-laoli-suite/sd-decision-engine/`
>
> **本文件是"选什么"，不是"怎么写"。** 具体机位写法归 `templates/A2-30秒分镜表` 与 `15-cinedance-six-locks.md`。

## 一、为什么炼气阶需要这一层

四阶·炼气做的是「气成序」——把图编排成时空。

但一直缺一环：**凭什么这么排？**

同一场"女主鼓起勇气告白"的戏：
- 长焦仰拍缓推？
- 广角手持快摇？
- 正面居中静态？

三种都对，但**选错就废**。没有依据时，AI 只能临场发挥——结果就是：同一个项目里，同类情绪戏每次拍法都不一样，情绪曲线无法规划。

**这一层就是火候的"度"。** 丹道讲"进火退符"，火大了伤丹，火小了丹不成。镜头选型也是：同一个情绪，用重了腻，用轻了不到位。

## 二、80/15/5 权重：把自由发挥从 100% 压到 20%

每个情绪节拍选定情境后，按三层分配：

```
┌─ 核心组合（80% · 锁死必用）─────────────────────┐
│ 从 ID 表直接复制，全部用上                        │
│ ❌ 不许替换 / 删除 / 自由发挥                     │
└──────────────────────────────────────────────┘
┌─ 辅助锚点（15% · 选 1–2 条）───────────────────┐
│ 按剧本细节挑，只能从该 ID 的锚点池里选             │
└──────────────────────────────────────────────┘
┌─ 增强项（5% · 每段最多 1 镜）──────────────────┐
│ 只用在情绪最高峰那一镜。滥用即失效                 │
└──────────────────────────────────────────────┘
```

> **道教口径**：核心 80% 是**武火**（定死，不许动），辅助 15% 是**文火**（微调），增强 5% 是**一点真意**（只在关键处用一次）。
>
> **一次只用一点。** 全是高潮等于没有高潮。

## 四、辅助锚点池（15% 选用，选 1–2 条）

从**本 ID 对应**的锚点里选，禁跨 ID 混用。

| 类别 | 可用锚点 |
|:---|:---|
| **焦段变化** | 换相邻焦段（长焦→中长焦 / 广角→中焦）制造呼吸感 |
| **机位高度** | 微仰 / 微俯（幅度小于核心组合的仰俯） |
| **前景插入** | 加虚化物件（门框 / 树叶 / 酒杯）造纵深与窥视感 |
| **光线调整** | 侧逆光 / 轮廓光强化边缘；主光暖冷互换 |
| **运动微调** | 缓推→固定 / 固定→微摇 / 手持微动升级 |
| **空间压迫** | 压缩留白 / 加大主体占比 / 前移后景层 |
| **细节插入** | 加一个手部 / 眼神 / 道具插入镜（不占额外节拍） |

## 五、增强项池（5%，每段最多 1 镜）

**必须命中该段最高情绪峰值。** 滥用即失效。

| 增强项 | 效果 | 前提 |
|:---|:---|:---|
| **滑动变焦**（Dolly Zoom） | 空间扭曲、眩晕、认知崩塌 | 顿悟 / 失控瞬间 |
| **环绕运镜** | 360° 环绕，强调孤立或震撼 | 情绪顶点、身份揭示 |
| **极限景别跳跃** | 大远景 ↔ 微距直跳，视觉重锤 | 转折点、时间跳跃 |
| **升降镜头** | 大幅升降，格局变化 | 命运转折、视角跃迁 |
| **慢动作定格** | 时间凝滞 | 目的须为"被截图/强调"，**不是拖延** |

> **配额共享**：荷兰角 ≤1/集、大仰角 / 大俯角各 ≤3/集、剧烈晃动 ≤3 段落。增强项与这些共享上限，**不得超配**。

## 六、选 ID 的四步（不许跳步，不许编造）

```
1. 查基础表（12 个）→ 命中即用
2. 查进阶表（3 个）→ 命中即用
3. 都没有 → 停下问用户：
   "本节拍情境（如'失忆中的恍惚'）不在标准库中，
    请提供：期望核心组合（焦段+机位+运镜）/ 风格参考片"
4. 用户授权 → 定义 EX01，标注"用户自定义情境"
```

> ⛔ **禁止 AI 临时编造 ID**。编一个 `E16 悲伤逆流成河`，看着合理，实际是把体系变成了自由发挥——那就退回原点。

## 七、切割节拍：3–5 个，不多不少

炼气阶的第一步不是选镜头，是**切节拍**。

| 规则 | 说明 |
|:---|:---|
| **3–5 个** | 超过 5 个 → 这场戏该拆成两段；少于 3 个 → 戏不够，别硬凑 |
| **一句话说清** | 每个节拍必须能一句话讲明白「谁在做什么 + 情绪是什么」 |
| **必须有变化** | 4 个节拍情绪完全相同 = 戏没推进，回去改剧本 |
| **同段可重复 ID** | 但动态变化要靠辅助锚点承担，不能靠换 ID |

> **这是丹道里的"分火候"**：一整段戏是一炉火，要分成几段火来烧。分段不对，火候全乱。

## 八、雷区：两类，一类永不解锁

| 类 | 数量 | 能不能解锁 | 说明 |
|:--:|:--:|:--:|:---|
| **A 类** | 7 条 | ✅ 可白名单解锁 | 构图惯例（如正面居中），在特定情境下可用，但须标理由 + 配套约束 |
| **B 类** | 7 条 | ❌ **永不解锁** | 工程性错误（物体穿身、服装突变），不是风格问题，是废片 |

### A 类常见 7 条

| 编号 | 雷区 | 什么情况下可解锁 |
|:--:|:---|:---|
| A1 | 正面居中 | 仪式感 / 审问对峙 / 权力宣示（E02 / E04 / E10 / E13） |
| A2 | 头顶贴边 | 表现压迫与被困（E14） |
| A3 | 强对称 | 异化、制度感（E13） |
| A4 | 大特写占满 | 情绪极端尖峰，且前后有呼吸 |
| A5 | 空镜无主体 | 只允许作为转场，≤1 秒 |
| A6 | 逆光全黑脸 | 神性 / 死亡 / 超验（E15） |
| A7 | 静态长镜 | 仪式、凝视、压迫（E10） |

> **解锁三件套**：① 在锚点表"解锁雷区"列显式标注 ② 写明理由（来自哪个 ID 的哪一条） ③ 配套后缀（如"强对称构图"）。**缺一条，视同违规。**

### B 类永不解锁（示例）

物体穿身 / 服装突变 / 手部崩坏 / 脸漂移 / 多手多脚 / 光影矛盾 / 空间矛盾。

> 这些不是"风格选择"，是**生成失败**。不能因为剧情需要就放过。

## 九、输出格式（三件套）

```
【大分镜 #BXX · 情绪锚点表】

| 节拍 # | 情绪关键词 | 服务的剧本动作 | 情境 ID | 核心组合（80% 定死） | 解锁雷区 |
|---|---|---|---|---|---|
| 1 | 隐忍 | 攥紧拳头不发作 | E08 | 过肩 + 长焦 + 手持微动 | — |
| 2 | 决意 | 抬头直视 | E09 | 长焦 + 仰拍 + 缓推 | — |

【本段情境对照】
- 节拍 1：隐忍不发 → E08 内向退缩
- 节拍 2：终于抬头 → E09 突破内心

本段选择 2 个分镜，原因：情绪只有"压"和"起"两个转折，
中间无第三态，加镜会稀释。

【雷区判定】（如有）
- 节拍 2：命中 A1 正面居中 → 解锁（E09 白名单第 1 项）· 配套后缀"仰角加强"
```

**不输出**：最终分镜稿、投喂提示词、时长标注、焦段数值细节。

## 十、与已有内容的分工

| 层 | 管什么 | 在哪 |
|:---|:---|:---|
| **本文件（18）** | **选什么**（E-ID + 核心组合 + 权重） | 炼气阶入口 |

| `templates/05-10字段分镜表` | 分镜正式格式 | 炼气阶产出 |

> **两层不越界**：本文件决定"为什么用这个镜头"，六把锁决定"这个镜头怎么写"。混在一起，两边都做不好。

## 十一、自查

- [ ] 节拍切成 3–5 个，每个能一句话说清
- [ ] 每个节拍都有 E-ID，且来自基础表 / 进阶表 / 用户自定义
- [ ] 核心组合 80% 完全照抄，未做任何替换
- [ ] 辅助锚点 1–2 条，来自该 ID 的池子
- [ ] 增强项全场 ≤1 镜，且用在情绪峰值
- [ ] A 类解锁都写了理由 + 配套后缀
- [ ] B 类一条没解锁
- [ ] 节拍之间有情绪变化，无 4 个相同
- [ ] 与本集景别阶梯、机位配额无冲突
