# 16 · 60/30/10 调色板与光影规范

> **补的是原始路由卡 9.10.6 缺口清单第二梯队第 ④ 项**——「场景包每场景加 16 项锁定表 + 60/30/10 调色板」与第三梯队第 ⑧ 项「FOV° 对照表」的配套内容。
> LIRA 反失败第 6 条明写：**60/30/10 调色板，不凌驾参考**。

---

## 一、60/30/10 是什么

一张画面里的颜色配比：

| 占比 | 角色 | 是什么 | 心理作用 |
|:--:|:---|:---|:---|
| **60%** | **主导色**（Dominant） | 画面最大面积的底色：墙面、地面、天空、大件家具 | 定情绪基调 |
| **30%** | **辅助色**（Secondary） | 次大面积：服装主色、窗帘、主要道具 | 定人物归属与场景层次 |
| **10%** | **点缀色**（Accent） | 小面积高对比：血迹、灯火、唇色、某个道具 | 引导视线焦点 |

> **为什么是 60/30/10 而不是随便配**：这是人眼在 0.3 秒内读图时，判断"这是什么地方、该看哪里"的天然比例。比例一乱，画面就"脏"——不是难看，是**看不懂**。

---

## 二、三个硬规矩

| # | 规矩 | 说明 |
|:--:|:---|:---|
| **1** | **每场景一套** | 同一场景跨集复用同一套 60/30/10。换套必须在总索引登记 |
| **2** | **不凌驾参考** | 已有锁定参考图时，调色板**服从参考**，不许为凑比例改参考色 |
| **3** | **写进 Prompt 用色名 + 比例** | `dominant warm ochre (60%), secondary deep teal (30%), accent dried-blood red (10%)` |

> ⛔ **禁止**只写"色调温暖""冷色调"这种词。必须给**色名 + 占比**。模型对色名响应准，对"温暖"响应随机。

---

## 三、场景调色板模板

每个场景在场景包该 S 节下加这一段：

```markdown
### S1 调色板（60/30/10）

| 层 | 占比 | 色名（中/英） | 具体落在什么上 | HEX 参考 |
|:--:|:--:|:---|:---|:---|
| 主导 | 60% | 陈年土黄 / aged ochre | 泥墙、地面、供桌木色 | #A8875C |
| 辅助 | 30% | 深靛蓝 / deep indigo | 帷幔、林昭外袍 | #2C3A4B |
| 点缀 | 10% | 干血红 / dried blood red | 烛火、门联残片、铜器反光 | #8B2E22 |

**光影基调**：单一窗光从画左斜入，硬边阴影，暗部保留细节不压死
**英文一行（投喂用）**：`palette: aged ochre 60% / deep indigo 30% / dried blood red 10%; single window light from camera-left, hard-edged shadows, open shadows with retained detail`
```

## 四、全剧色调谱（避免"每场一个色"）

12 个场景各配一套，很容易变成彩虹。**全剧要有节制**：定 3–5 个色系，场景在其中取。

| 色系 | 主导色 | 适合什么场景 | 情绪 |
|:---|:---|:---|:---|
| **土系** | 赭石 / 土黄 / 陶红 | 祠堂、老宅、市井 | 沉、旧、根 |
| **青系** | 靛蓝 / 石青 / 墨绿 | 夜戏、官府、雨景 | 冷、压、密 |
| **白系** | 灰白 / 米 / 冷白 | 医院、雪、清晨 | 空、净、危 |
| **金系** | 暖金 / 琥珀 / 蜜色 | 回忆、烛光、喜庆 | 暖、幻、逝 |
| **黑系** | 墨黑 / 深褐 / 铁灰 | 打斗、暗室、结局 | 死、决、闭 |

> **建议**：全剧主用 2 个色系（如土 + 青），第三色系只在关键节点出现一次。**色系切换本身就是叙事信号。**

## 五、光影四要素

调色板管"什么色"，光影管"怎么亮"。四个必须写清的：

| 要素 | 写什么 | 例子 |
|:---|:---|:---|
| **光源方向** | 从画左 / 画右 / 顶 / 底 / 逆 | `single window light from camera-left` |
| **硬软** | 硬边（直射）/ 软边（散射） | `hard-edged shadows` / `soft wrap, overcast` |
| **明暗比** | 亮部与暗部差几档 | `3:1 key-to-fill, shadows retained` |
| **特殊处理** | 逆光/剪影/轮廓光/丁达尔 | `rim light on shoulders, face in shadow` |

### 三条禁则

| ⛔ 禁 | 为什么 |
|:---|:---|
| **平光美容光** | 无立体感，像影楼。**逆光人脸允许沉影** |
| **暗部压死** | 死黑一片，细节全失，后期救不回 |
| **多光源无主次** | 模型不知道跟谁，光影必乱 |

> **逆光人脸允许沉影**——这是 LIRA 明确写的。很多人怕人脸黑，拼命补光，结果画面假。**该黑就黑。**

## 六、SOP 里的光影段怎么写

在《图片视频生成执行规范 SOP》的固定前缀区，加一段：

```
光线：单一主光源从「画左 / 画右 / 顶 / 逆光」，硬边阴影，明暗比约 3:1；
暗部保留细节，不压死；逆光时人脸允许沉影，不做补光美容光。
Lighting: single key from camera-left, hard-edged shadows, 3:1 key-to-fill,
shadows retained with visible detail, rim-lit profiles allowed to fall into
shadow; no flat beauty lighting.
```

## 七、一致性检查（出图后必做）

拿成品图对照调色板，逐项核：

- [ ] 主导色确实占约 60%（肉眼估，允许 ±10%）
- [ ] 辅助色约 30%，且落在预期物件上
- [ ] 点缀色约 10%，且**只在要引导视线的地方**
- [ ] 光源方向与设定一致（画左就是画左）
- [ ] 阴影是硬边还是软边，符合设定
- [ ] 暗部有细节，没压死
- [ ] 没有平光美容光
- [ ] 与同场景前一场次的色彩一致（跨集比对）

> **不一致怎么办**：先查 Prompt 是不是漏了色名；再查参考图是不是换了；最后才考虑重出。**八成是 Prompt 没写清，不是模型不行。**

---

## 八、常见错误

| 错误 | 症状 | 修法 |
|:---|:---|:---|
| 只写"色调温暖" | 每次出来的色都不一样 | 改成 `warm ochre 60% / ...` |
| 三色都饱和 | 画面花、看着累 | 主导色降饱和，只让点缀色饱和 |
| 点缀色太多 | 观众不知道看哪 | 点缀色只留一处，其余降为辅助色 |
| 每场景换色系 | 全剧像拼盘 | 收敛到 3–5 个色系 |
| 逆光还补光 | 人脸假、像贴图 | 允许沉影 |
| 暗部死黑 | 后期拉不回来 | Prompt 加 `shadows retained with detail` |

---

## 九、一句话

> **调色板不是审美偏好，是可复现的配方。**
> 写清 60/30/10 和光源方向，十次出图有八次一致；写"温暖一点"，十次十个样。
