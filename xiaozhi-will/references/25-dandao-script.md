## 总纲：采药六候

内丹采药讲"六候"——**什么时候采、采到什么程度、什么时候收**，都有定候。

剧本也是六候。**候不到就往下走，后面全是虚的。**

> **判据**：**阶段状态只有六种，不许自创。**
> `NOT_STARTED` / `IN_PROGRESS` / `AWAITING_CONFIRMATION` / `AWAITING_USER_DECISION` / `LOCKED` / `STALE` / `BLOCKED`

## 附 · 台词自然化（采药后的"洗药"）

### 三条总则

| # | 总则 |
|:--:|:---|
| 1 | **口语化 ≠ 加废话** |
| 2 | **口语化 ≠ 拉低身份**（粗人糙话、书生引典、杀手惜字） |
| 3 | **台词是服务剧情的工具**——宣判段 / 静场留白**本就不该口语** |

### 称呼 = 四轴

```
身份轴 × 关系轴（生疏/熟识/亲密/决裂/旧情/上下级）× 场合轴（公开/私密）× 情绪轴
```

**七情境变体**：公开尊称 / 私下简省 / 亲密昵称 / 示弱升格 / 恼火直呼全名 / 挑衅贬称 / 划界退回

**三铁律**：
1. 同一关系阶段称呼**稳定**；变化需**事件触发**并登记
2. 称呼是「体温计」不是「推进器」；只改称呼不改行为 → 标 `ADDRESS_ONLY_SHIFT`
3. 不同角色对同一对象称呼要有**区分度**

### 现代赛道禁用虚词（出现即标记）

⛔ `是否` `因此` `从而` `鉴于` `予以` `加以` `可否` `何以` `颇为` `甚为` `以及` `然而` `由于` `进行` `兹`

**替换**：是否→是不是 / 因此→所以 / 以及→还有 / 由于→因为 / "进行+名词"→直接用动词

> **只查台词文本，不查画面/叙述段。**

### 古装违和现代词

⛔ `逻辑` `数据` `机制` `效率` `系统` `项目` `团队` `版本` `反馈` `状态` `维度` `定位` `复盘` `闭环` `赋能` `抓手` `颗粒度` `情绪价值` `经济损失` `沟通` `心理` `压力`

（"节奏/关系"作具体义可用）

⛔ **禁止把"臣不敢"改成"我不敢啦"。**

### 句式四处方

| # | 处方 |
|:--:|:---|
| 1 | 成对关联词**后半截常不说** |
| 2 | **删主语**（口语大量省略） |
| 3 | 被动改主动 |
| 4 | 一句说完前**插入至少一处停顿标点** |

### 撒碎屑四法 + 借物

| 法 | 做法 |
|:--:|:---|
| **打断** | 自己推翻半句 |
| **掉尾** | 说一半留给对方 |
| **重复** | 只重复关键词 |
| **语气词与垫词** | 句尾：啊吧呢嘛呗啦呀哦咯 / 前置：那什么、我说 / 应答：嗯唉哎嘿哟啧 / 程度：贼、巨、超、老 |
| **借物说话** | `（把杯子推回去）……茶凉了` |

### 机械化认症表 10 条

等长句 / 零语气词 / 全完整句 / 人人同口吻 / 信息均匀分配 / 说明式对白 / 书面连接词 / **情绪结果词**（"我很愤怒"）/ 全员敬语或全员粗口 / 复读

### 同口吻三测试

> 三条都是**可算/可操作**的，不是感觉。判不过 = 该角色台词重写。

| # | 测试 | **怎么测**（执行动作） | 判不过 |
|:--:|:---|:---|:---|
| 1 | **遮挡名测试** | 把该角色 10 句台词的**角色名盖住**，给一个没读过剧本的人看，请他指认是谁说的 | 认不出，或指错人 → **不合格** |
| 2 | **句长方差测试** | 统计该角色连续 5 句的**字数**，算标准差（Excel `STDEV`／手工算） | 标准差 **<2 字** → **不合格**（句子长度太均匀＝机械） |
| 3 | **专属词测试** | 列出该角色的**专属用词**（口头禅/称呼/语气词/行业词），数个数 | **<3 个** → **不合格**（没有声音指纹） |

> **证据留法**：① 遮名后谁猜的、猜成谁；② 5 句字数与算出的标准差；③ 专属词清单（≥3 个）。

### 密度铁律

> 全部可数，不靠听感。

| 项 | **怎么测** | 值 | 判不过 |
|:---|:---|:---|:---|
| 每 15 秒 | 按 15 秒切片，**数人声事件**（一句台词＝1，一声叹息＝1） | **≥2 条** | <2 条 → **不合格** |
| 段台词字数 | **数字数**，与本段秒数比 | ≈ 秒数 × 3.5~6.5（90 秒集 ≈300~580 字） | 超出区间 → 重写 |
| 实测语速 | 字数 ÷ 秒数 | 4.0~6.4 字/秒 | 超出 → 调整 |

**信息优先由反派/配角台词说出**，不靠旁白。

**金句四式**：先接住再拐一刀 / 归谬堵嘴 / 动作描述改反问+指令 / 加生理或日常词

**四自检问句**：
1. 能否被对方听见？
2. 有无接住上一句？
3. 观众需不需要想几秒？
4. 删掉剧情断不断？

## 附 · 台词诊断七维

| # | 维 | 红线 |
|:--:|:---|:---|
| 1 | **角色辨识度** Voice Print | 遮住名字认不出谁在说 / 台词换给他人无违和 |
| 2 | **潜台词层级** Subtext | 全部 0 层直白（"我很愤怒"） |
| 3 | **冲突推进力** Conflict Drive | 连续 3 句以上无任何推进 |
| 4 | **类型语感** Genre Voice | 古装出现"经济损失/逻辑漏洞"等现代词 |
| 5 | **信息效率** Info Efficiency | 连续两句设定灌输、自报家门 |
| 6 | **节奏与音乐性** Rhythm | 连续 30 字以上无气口 / 通篇齐整短句。标准：**单句 6~18 字**，金句前留 0.5s 发酵 |
| 7 | **金句潜力** Memorable Line | 属**加分项非底线**；一集 1~3 句即可，**满篇金句 = 没有金句** |

**输出契约**：必须「原台词 → 改写建议 → **为什么这么改**」，且**理由 ≥3 条维度依据**，缺则判不合格重做。

> 本框架只做诊断，**不改台词、不改结构、不涉分镜**。实际改写回五候执行。

## 附 · 台词语速硬指标

### 四档

| 档 | 字/秒 | 用途 |
|:---|:--:|:---|
| 慢速重音 | 2.5~3.5 | 金句 / 遗言 / 情绪顶点 |
| 标准 | 3.5~5 | 常规 |
| 快速 | 5~5.5 | 争吵 / 逼问 |
| 高速 | 5.5~6 | 短剧常态快念 |
| ⛔ 超 6 | — | 需授权，仅短句，须写明快念 |

### 公式

```
口播时长 = 可发音字符数 ÷ 语速
最快可行 = 字数 ÷ 6          ← 唯一判定基准
最慢舒适 = 字数 ÷ 3.5
合法区间 = [字数/6, 字数/3.5]
```

> `字数÷6 + 停顿 ≤ 镜长` → 判「念得完」。
> ⛔ **不得误判超载、不得建议精简。**

### 字数口径

**只数可发音字符**（汉字/数字/字母），标点不计。
**停顿另算**：顿号逗号 ≈0.1~0.3s；句号感叹问号 ≈0.3~0.6s。

### 判定分级

| 级 | 条件 |
|:--:|:---|
| ✅ 合规 | 语速 3.5~6 字/s **且单句 ≤24 字** |
| ⚠️ P1 | 单句 >24 字 → **强制拆镜，每镜 ≤18 字** |
| ⚠️ P2 | 金句后无 0.3~0.8s 反应镜头 |
| 🔴 P0 | 连 `字数÷6+停顿` 都塞不进镜长 |
| ℹ️ | 5~6 字/s 仅为"需快念"提示，**非缺陷** |

### 每镜字数密度（第二把尺，只作拆镜提示）

| 镜长 | 台词 | 独白 |
|:--:|:--:|:--:|
| 2s | ≤6 | ≤8 |
| 3s | ≤10 | ≤12 |
| 4s | ≤15 | ≤16 |
| 5s | ≤20 | ≤25 |

**无台词/无独白镜 ≤3 秒。**

> 超密度**优先拆镜，台词逐字保留不得删改**。

### 密度下限（只对对话段生效）

| 段类型 | 下限 |
|:---|:---|
| 对话段 | ≥2.0 字/秒（15s ≥30 字）、开口 ≥6 次/15s |
| 混合段 | 1.2 字/秒（15s ≥18 字、≥3 次） |
| 打斗段 / 空镜段 | **不设下限**（空镜带先声合法） |

**补台词四来源**：OS 补位 / 短句化拆解 / 加对方回嘴 / ⛔ **不得拉长文采凑字**

**单组对白总时长 + 动作时长 ≤ 15s。**
