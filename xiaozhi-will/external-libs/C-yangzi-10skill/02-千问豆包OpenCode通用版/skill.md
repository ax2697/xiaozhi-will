# 02-千问豆包OpenCode通用版

平台无关的通用适配器：弹性总控系统指令 + 8 个专业模块 + 可选本地知识桥 + 中文口令卡，供豆包工作模式、千问工作台与 OpenCode 读取。

## 本目录文件

- **00-使用说明.txt**（9KB）：V3 弹性工作流使用说明。全平台单包说明、项目/工作模式、一包安装与手工搭建备用方法、普通聊天临时用法、项目防污染、主动调用知识库后各阶段可查范围、推荐中文口令、回退操作。
- **01-通用总控系统指令.txt**（15KB）：通用总控系统指令全文（可整体粘贴为系统提示词）。一次只用一个模块、首次入口门禁 A/B/C/D、四种运行状态（全流程 / 指定阶段 / 接力 / 修订）、8 个模块清单、01 概念锚定硬门禁、知识桥默认未调用与知识库 A/B/C 选择、跨阶段参考记忆、权威顺序、配置/更新知识库口令等。
- **02-中文口令卡.txt**（3KB）：推荐中文口令速查卡（从零开始 / 从已有资料接力 / 整场戏拆镜头 / 资产修改 / 确认与修改 / 主动调用知识桥 / 主动补查 / 跨阶段沿用与控制 / 第一次配置知识库 / 增加新资料后 / 回退 / 结束）。
- **03-空白项目状态卡.md**（916B）：项目状态卡空模板（项目入口 / 模式 / 当前阶段 / 本轮权威输入 / 知识桥状态 / 作者剧本锁定 / 生产资料状态 / 视频模型 / 镜头规划 / 连续性模式 / 下一步），只记录控制状态不放示例内容。
- **04-跨阶段参考记忆模板.md**（3KB）：跨阶段参考记忆模板。用户第一次明确调用知识库时复制为该电影项目内 `00-本地知识库参考记忆.md`；含权威顺序、使用规则、参考方法编号、使用范围、新增条目字段、变更记录与阶段应用记录。
- **AGENTS.md**（5KB）：通用总控 AGENTS 规则。汇总总控 / 8 模块 / 知识桥的执行边界：入口门禁、08 两步、每条提示词独立写全连续性、参考记忆创建时机、知识库配置与更新口令、整理新剧本口令等。
- **_索引.md**：本目录索引。

## 子目录

- **专业模块**：8 个创作模块（01 概念锚定 … 08 CINEDANCE 视频提示词）。
- **本地知识库外挂**：可选知识桥（系统指令、中文口令、knowledge-base.json、新剧本自动整理规则、tools 脚本）。
