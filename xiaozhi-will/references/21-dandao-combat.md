# 21 · 炼形 · 打戏体系（道教改写）

> **归位**：五阶 · 炼神（P4 生成）· 打戏分支
> **来源**：漫剧老李 V5.0.2 武打体系（MIT），原文在 `external-libs/D-laoli-suite/legacy-v5/`
> **改写**：用道教"炼形"逻辑重组——**形不正则气不顺，气不顺则力不达**。

---

## 总纲：打戏是"炼形"

内丹讲"炼精化气"，但先要有"形"——形不正，气无所依。

打戏就是"形"的工程：**力从哪来、经哪走、落在哪**。

大多数人写打戏只写"打"，不写"力怎么来"。结果就是：**动作再花，也是飘的。**

> **一句判据**：**观众不信这一拳能打倒人，这场戏就白拍了。**

---

## 一 · 十一环动力链（打戏的骨架）

### 道教原义：周天

炁行周天，有固定路径：**尾闾 → 夹脊 → 玉枕 → 百会 → 任脉下行**。路径断了，周天不成。

**打戏的力也有固定路径：十一环。少一环，力就断。**

### 十一环

| # | 环 | 写什么 | 漏了会怎样 |
|:--:|:---|:---|:---|
| 1 | **动作意图** | 这一下要干什么（打倒 / 逼退 / 试探 / 诱敌） | 观众不知道他在干嘛 |
| 2 | **起手准备** | 蓄力前的姿态（下沉 / 后撤 / 抬手） | 动作突然发起，假 |
| 3 | **重心变化** | 重心移到哪只脚 | 人像纸片，一推就倒 |
| 4 | **脚步位移** | 上步 / 撤步 / 转步 / 垫步 | 力无根，发不出来 |
| 5 | **腰胯 / 核心发力** | 力从腰起（不是从手起） | 只有胳膊动，是假打 |
| 6 | **肩肘腕 / 髋膝踝传导** | 力如何一节节传过去 | 力在半路丢了 |
| 7 | **攻击轨迹** | 从哪到哪，什么弧线 | 观众看不清打哪 |
| 8 | **接触点** | 具体打在对方哪个部位 | 打空气 |
| 9 | **命中 / 格挡反馈** | 对方怎么反应（退 / 晃 / 挡 / 摔） | 打完没事，假 |
| 10 | **收招惯性** | 打完后身体因惯性往哪走 | 打完立定，像摆拍 |
| 11 | **下一格继承状态** | 这一下的结果如何变成下一格的起点 | 镜头之间断开 |

> **核心洞察**：**力的源头在腰，不在手。**
> 只写手部动作的打戏，无论怎么花，都是"舞"不是"打"。

### 写法示例（一段完整 11 环）

```
1 意图：逼退，不取命
2 起手：右脚后撤半步，右肩下沉
3 重心：七成在后腿，前腿虚点
4 位移：前脚蹬地，重心前送 20 公分
5 发力：腰胯右转 45 度
6 传导：肩随腰转 → 肘送出 → 腕在接触瞬间锁死
7 轨迹：从右下向左上，弧线（不是直线）
8 接触：对方左前臂外侧，尺骨位置
9 反馈：对方手臂外翻，上身向左偏 15 度，退半步
10 惯性：我方右肩继续前送，身体略过中线
11 继承：下一格从"过中线"起手，接左手反击
```

## 二 · 打击感的三件套（Hit-Stop）

### 道教原义：顿

丹道讲"顿悟"——**一刹那的停，比连续更真**。

打击感同理：**没有停顿，就没有力量。**

### 三件套（缺一必飘）

| 件 | 做法 | 为什么 |
|:--:|:---|:---|
| **一 · 微停顿** | 接触瞬间 1–2 帧停住 | 打破平滑插值。**模型默认会平滑过渡，一平滑就假** |
| **二 · 接触点迸发** | 火花 / 尘土 / 碎屑，从接触点向外 | 观众用这个判断"打实了" |
| **三 · 高频震颤声** | 金属咬死的高频 screech | 听觉补视觉 |

> **这三件是打戏的"命门"。** 三件缺一，动作再标准也发飘。

## 三 · 三套物理，不能混用

### 道教原义：三才各有所属

天、地、人三才，各有其道。**拿天道套人道，必乱。**

打戏也是：**写实 / 玄幻 / 漫剧打斗，是三套不同的物理。**

| | 写实武打 | 玄幻战斗 | 漫剧打斗 |
|:---|:---|:---|:---|
| **力从哪来** | 真实肌肉骨骼 | 内力 / 灵力 | 情绪张力 |
| **能不能飞** | ❌ 不能 | ✅ 能 | ⚠️ 可短暂滞空 |
| **伤害反馈** | 瘀青 / 骨折 / 脱力 | 吐血 / 内伤 / 经脉断 | 夸张击飞 / 变形 |
| **镜头** | 长焦压缩 + 手持 | 广角仰拍 + 环绕 | 快速切换 + 升格 |
| **节奏** | 五拍（见下） | 蓄—爆—余波 | 快切 + 定格 |
| **代表** | 现代格斗、民国武行 | 修仙、玄幻 | 漫剧、二次元 |

> **⛔ 最常见错误**：拿漫剧的夸张去拍写实戏，或拿写实的克制去拍玄幻戏。
> **两者都"不对味"，但错因相反。**

### 写实五拍（walking rhythm）

真人打斗不是连续的，是**五拍**：

```
1 起  → 2 行  → 3 触  → 4 应  → 5 收
```

每拍之间有微小的"空"。**这五个空，是写实感的来源。**

## 四 · 白模预演（15 格）

### 道教原义：先画符，后行法

道教行法前先画符——**把意图先落在纸上，确认无误再动真格**。

打戏的白模预演就是这个"符"。

### 规则

| 项 | 规定 |
|:---|:---|
| **格数** | **15 格，不多不少**（5 列 × 3 行） |
| **编号** | P01–P15，从左到右、从上到下 |
| **每格** | 只表现**一个**清晰、独立、可动画的静态动作节点 |
| **禁止** | 漏格 / 重复格 / 错序 / 第 16 格 |

### 白模风格（为什么是白的）

**全部转为哑光白 / 象牙白 / 浅暖灰的无纹理 3D 模型。**

| 只保留 | 禁止 |
|:---|:---|
| 身高、体型、脸型轮廓 | 真实肤色 |
| 发型轮廓、服装剪裁 | 真实发色 |
| 配饰轮廓、武器 | 彩色眼睛 |
| 战斗姿态、站位 | 皮肤毛孔 |
| 简化面部体块 | 真实布料/金属色 |

> **为什么去色**：**颜色会干扰对"力"的判断。**
> 去掉颜色，你只能看结构——**而结构对了，戏就对了。**

### 必须保留的

- 人体体块
- 肌肉受力关系
- 武器接触点
- 地面接触点 + 阴影 + 投影
- 前后景层次
- **战斗空间纵深**

> ⛔ **禁止全白一片**——用浅灰明暗和环境遮蔽表现结构。
> 全白 = 看不到结构 = 白做了。

## 五 · 空间：轴线与边界

### 道教原义：界

道教讲"结界"——先划定范围，法才有效。

打戏的空间也要先划界。

### 三定

| 定 | 内容 |
|:--|:---|
| **一 · 定轴** | 180° 轴线。全段不能越。越了就是"跳轴"，观众瞬间迷失方向 |
| **二 · 定界** | 战斗边界在哪（墙 / 桌 / 台阶 / 悬崖）。**边界决定走位** |
| **三 · 定高低** | 有无高低差（楼梯 / 台阶 / 桌面）。**高低差是打戏最好的调度工具** |

> **一个实用技巧**：**把对手逼到边界，戏就紧了。** 无边界打斗，永远不紧张。

## 六 · 多人对打

### 道教原义：以一敌众，先分主次

一打多不是"轮流上"，是**始终只有一个真威胁**。

| 规则 | 说明 |
|:---|:---|
| **同时只打一个** | 其余人在"等待区"，做反应不做攻击 |
| **等待区要合理** | 有人被地形挡、有人在恢复、有人不敢上 |
| **轮换要有理由** | 不能"这个倒了下一个自动补位"——太假 |
| **一打多靠地形** | 借柱子、借桌椅、借门框，制造"一次只面对一个" |

## 七 · 物理真实

### 三条硬规

| 规 | 内容 |
|:--:|:---|
| 一 | **重力与质量**：重的东西下落快，轻的会被带飞。刀比拳重 |
| 二 | **惯性**：打完不会立定，会继续走半步 |
| 三 | **液体抛物线**：血、水、酒，走抛物线，不走直线 |

> **最常犯的错**：**人被打飞后，落地就停。** 真实的落地会弹一下、滑一段。

## 八 · 自查

- [ ] 每个动作都有完整 11 环（至少不漏 3/4/5/8/9）
- [ ] 力从腰起，不是从手起
- [ ] 三件套齐全（微停顿 / 迸发 / 震颤声）

- [ ] 白模 15 格齐，无漏无重无第 16 格
- [ ] 去色彻底，无真实肤色发色

- [ ] 战斗边界明确，走位有依据
- [ ] 多人戏同时只有一个真威胁
- [ ] 重力 / 惯性 / 抛物线成立
