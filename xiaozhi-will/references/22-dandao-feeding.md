# 22 · 投喂 · 七段式与六道闸门（道教改写）

> **归位**：五阶 · 炼神（P4 生成）
> **来源**：漫剧老李 V7.4.26 `sd-feed-engine` + 总控 `prompt-feeding-checklist`（MIT）
> **改写**：用道教"画符"逻辑重组——**符不成，法不灵**。

---

## 总纲：投喂是画符

道教行法，先画符。符有固定格式：**符头、符胆、符脚**，一笔不能错，错一笔法就废。

投喂提示词就是画符。**七段是符的七个部位，六道闸门是画符的六道手续。**

> **判据**：**格式错一个字，整段返工。** 不是"差不多"，是"逐字"。

---

## 一 · 七段式：符的七个部位

| 段 | 符位 | 写什么 | 关键纪律 |
|:--:|:---|:---|:---|
| **①** | **符头** | 画幅风格（含 `model=` 版本） | 常规稿不写段 8/9；美学短语 **≤30 字**，如`冷青灰低饱和 · 光比 1:5~1:8 单侧光 · 35~85mm 中浅景深`。焦段与光比**只在这段写**，不许塞进镜行 |
| **②** | **符身** | 场景资产 `@SCN-xxx（参考图N）；@PRP-xxx（参考图M）` | **极简**。严禁二次介绍陈设 / 外貌 / 材质——文字会覆盖参考图 |
| **③** | **符心** | 核心人物锚定句 | 全部在场角色须**具名 + 具象 + 定位 + 状态** |
| **④** | **符骨** | 站位声明（一行式） | 每人一段括号四要素：**位置（画左/右/中）+ 依托物 + 朝向 + 姿态**。多镜加轴线行。**禁 ASCII 空间图 / 坐标表** |
| **⑤** | **符脉** | 时间轴分镜 | 原生格式 `[镜头N] 景别 · 视角角度 · 运镜。动作。声音：…。台词：…。`。⛔ **不写「跟随@谁」**，⛔ **不写【接续状态】尾行**（已废止，出现即 FAIL） |
| **⑥** | **符音** | 音效 | 声音层。2.0 无官方声音字符，用文字描述写进镜行 |
| **⑦** | **符脚** | 强制禁止项 | **只装负面清单**。默认四项极简：`画面：禁字幕、禁水印（含 Logo）；音频：禁背景音乐、禁旁白`。⛔ **正向指令禁入**（会被当规避清单读），⛔ **否定式禁令也禁入**（被禁词根＝画面词） |

### 三种输出模式

| 模式 | 用途 | 镜数 |
|:--:|:---|:---|
| **A** 标准字段化 | 高精度 / 审查 | 1–3 镜 |
| **B** 导演执行增强 | 一镜到底 / 强运镜 / 人群 / 动作戏 | 按需 |
| **C** 导演轨纯净 | **默认** | 4–7 镜（高密度可 8–10，须过闸门） |

## 二 · 六道闸门：画符的六道手续

> **闸门 0 · 结构完整性**：`【】`配对 / 台词行收尾 / 镜号连续 / 必备字段。不过不进闸门 1。

### 闸门 1 · 节奏档位

先定节奏档（电影感中速 / 短视频中高密度 / 高密度动作或强钩子 / 慢节奏高信息）→ 查镜头密度。

**10 秒以上只有 1–2 镜** → 判是否命中慢节奏白名单。未命中须补：动作标点 / 道具信息 / 反应 / 空间关系 / 段末钩子。

### 闸门 2 · 台词时长（防"念不完"）

**唯一判定基准：最快档 6 字/秒。**

```
字数 ÷ 6 + 停顿 = 最短可行时长
镜长 ≥ 此值 → 合规
```

> ⛔ **不得判超载、不得建议精简。** 只要按 6 字/秒算得下，就是念得完。
> 舒适时长按 3.5–5 字/秒另算，仅作参考。

### 闸门 3 · 字数

| 模型 | 通过 | 先压一轮 | 必压 |
|:---|:--:|:--:|:--:|
| Seedance 2.0 / 未注明 | ≤1900 | 1901–2000 | >2000 |
| Seedance 2.5 | ≤2600 | 2601–3000 | >3000 |
| 单文件兜底 | ≤4500 字符 | | |

**超限按固定七步压缩**：删管理话术 → 删低收益后缀 → 合并重复限制 → 缩空泛形容词 → 缩非末镜转接 → 同控制点集中 → 换更短完整句。

### 闸门 4 · 可投喂语义

删掉模型执行不了的**交接话术**：
- ❌ `接下一大分镜` / `接下一段` / `承接上一段` / `接分镜2`
- ✅ 改成**可见动作 / 可见转接 / 段末状态**

平台参数（9:16 / 13-15秒 / 分辨率 / 模式 / 任务类型）**必须移到代码框外**。

### 闸门 5 · 图片数量

按模型上限：

| 模型 | 图 | 视频 | 音频 | 总数 |
|:---|:--:|:--:|:--:|:--:|
| H3 | ≤9 | ≤3 | ≤3 | ≤12 |
| Seedance 2.5 | ≤30 | ≤10 | ≤10 | ≤50 |
| Seedance 2.0 | ≤9 | — | — | — |

**闸门 5·补 · 分组三重门槛**

| 门槛 | 判据 |
|:--:|:---|
| A | 时长不超模型单段上限 |
| B | 单组引用图号 + @ 锚点合计 ≤ 模型上限（实操 ≤9 更稳） |
| C | **资产隔离**：同一角色不同形态 / 年龄 / 服装版本**不得同组**（否则模型"揉成一张脸"），编号可相邻，**组必须分开** |

### 闸门 6 · 素材一致性（九条判据）

| # | 判据 | 违规级别 |
|:--:|:---|:--:|
| ① | 每个 `图N/视频N/音频N` 已在映射表定义 | FAIL |
| ② | 角色 / 场景 / 道具 / 首帧 / 调度 / 视频 / 音频 职责未混用 | FAIL |
| ③ | 图号混用先修正，不直接交付 | WARN |
| ④ | 交付首行未声明 M0/M1/M2 | 不得交付 |
| ⑤ | M0 稿内出现图号 | FAIL |
| ⑥ | M1 有图号但无《素材接线单》 | WARN |
| ⑦ | 稿内图号 ∉ 接线单图号集合 | FAIL |
| ⑧ | 接线单缺「只控制什么 / 不控制什么」 | WARN |
| ⑨ | 出现「已与资产图册核对一致」而本包看不到图 | **FAIL（虚假核验）** |

> **第 ⑨ 条最关键**：这是"嘴上说验过了"的防伪门。**没看到图，不许说核对过。**

## 三 · 资产映射（码与图分离）

### 编号体系

**统一「图N」**（图1、图2…）+ `视频N` / `音频N`。

⛔ **禁用**：`@图片N` / `@ImageN` / `@Video N` / `@Audio N` / `asset-xxx` / `CH001` / `SC001` / `ST001`

### 先素材后画面

```
将 图N 中的[身份/外观/服装]定义为 <角色名>
```

**锚定句只写定义，不追加说明。** 锚定后只用 `<角色名>` 指代。

### 道具锚定

```
@PRP-道具名（外观以道具参考图锁定；状态：〔初始〕→〔终态〕）
```

写入【场景资产】栏，与 `@SCN-` 并列，**不增段**。

**只写关键道具**（承担叙事 / 跨镜一致 / 有状态变化）。场景固定陈设不写。

### 投喂顺序 = 优先级声明

```
场景 → 主角 → 初始武器/关键道具 → 进阶形态（相邻编号）→ 敌人/群演（可无图，纯文字）
```

> **群演省下的图位，让给更需一致的资产。**

### 引用红线 11 条（要点）

| # | 红线 |
|:--:|:---|
| 1 | 图号只能来自「用户提供」或「本次接线单显式定义」 |
| 2 | 参考总数按模型上限 |
| 3 | 非定稿须标风险 |
| 4 | 同角色尽量同号 |
| 5 | `视频N` 不得同时承担角色/动作/风格/构图四任务 |
| 6 | 音频须提醒版权 |
| 7 | 首帧只锁第 0 秒 |
| 8 | 角度图只锁空间方向与透视 |
| 9 | 六类图不能互相替代 |
| 10 | 首帧与调度图冲突 → **停止输出**先重做 |
| 11 | 内部 ID 不得进可投喂描述 |

**优先级**：首帧图 > 调度/侧别卡 > 场景角度图 > 场景母版 > 角色图 > 道具图

### 形态三档

| 档 | 含义 | 要点 |
|:--:|:---|:---|
| **M0** | 纯提示词 | 不写任何图号，改「外观档案复述」，禁「同上」 |
| **M1** | 编号占位（**默认**） | 必附《素材接线单》：图号→类型→用途→**你该挂哪张**→不控制什么 |
| **M2** | 已入库 | 用户交回图后登记资产图册 |

> **三不**：不索要图片、不因缺图阻断、不虚假核验。

## 四 · 工程语言清洗（丹道谓"去妄语"）

### 核心判据

> **凡是描述"镜头之间关系"、或"给创作者看的标注"，一律不是画面事实。**
> 要么翻成看得见听得见的东西，要么直接删。

### 必删（分镜层专用字段）

| 删什么 | 为什么 |
|:---|:---|
| `状态：{前}→{后}` | 描述镜与镜关系，不是画面 |
| `重音：{字}` | 模型配音不吃这个记号 |
| 台词精简建议清单 | 是与用户的对话，不是提示词 |
| 故事板面板号 / 出口帧六项 | 创作脚手架 |
| 机长时码 / 卡 ID | 同上 |
| 神态-动作供给库 / 锚点表 / 节拍表 | 同上 |

### 必转（翻成画面事实）

| 原文 | 翻成 |
|:---|:---|
| 180 度轴线 / 不要越轴 | 写清人物朝向与相对位置 |
| A2 点位 / B1 站位 | 写清具体位置 |
| 参考 MAP001 | 写清具体参照物 |
| 以沙盘为锚点 | 写清沙盘在哪、多大 |
| 前中远景层 | 写清各层有什么 |

### 必删（抽象词与编号直抄）

| 删什么 | 为什么 |
|:---|:---|
| `ST001 / CL001 / NP001 / 继承 ST` | 编号只能留代码框外，框内必须译成自然语言 |
| `电影级布光 / 高级光影 / 氛围感` | 空词，模型无法执行 |
| `悲伤 / 愤怒 / 害怕 / 心动` | 抽象情绪。须拆成：眼神、眨眼、嘴部、呼吸、肩颈、手部、重心的可见变化 |
| `CR001 / 同上一段人群` | 编号泄漏 |
| `添加一个道具` | 须写「不新增第二个实例」 |
| `SCV001 / 使用角度图` | 编号泄漏 |

### 必删（摄影机理论废话 · 会诱发莫名晃动）

⛔ 实测会**稀释人物动作 Token** 并诱发画面无故晃动：

- `85mm F1.4极浅景深（焦平面全程死锁面部无漂移）`
- `极细微规律呼吸式微动`
- `毫米级构图补偿`
- `画面线条笔直构图平整`

**正确分流**：焦段与光比进【画幅风格】段首；镜行只写「镜行头三要素 + 纯物理动作 + 句尾 6~10 字背景光影锚」。

### 其他

- 摄影机行为不能只写「固定/手持/跟拍/退拍」，必须**六要素齐全**：类型 / 位置 / 高度 / 方向 / 速度 / 起止 + 禁止项
- 风格光影冲突时**以当前镜头真实光源为准**，不写两套打架的光影
- 官方符号：`{台词}` `<音效>` `【字幕/标题】`
- 默认不生成 BGM；默认不生成文字（唯一例外：有来源的系统面板，须逐项可读、不得模糊补造）

## 五 · 硬指标速查

### 字数与时长

| 项 | 值 |
|:---|:---|
| 段时长上限 | 2.0 = 15s / 2.5 = 30s / H3 = 15s |
| 2.5 默认 | 25–30s，**禁 16–24s 碎段区** |
| 单镜 | 3–5s 为节奏参考；≤6s 硬上限 |
| 高密度 | 0.5–1.0s/片 |
| 镜数上限 | ≤ ceil(段长/3s)；对话段 ÷2s |

### 台词

| 项 | 值 |
|:---|:---|
| 语速四档 | 2.5–3.5（重音）/ 3.5–5（标准）/ 5–5.5（快速）/ 5.5–6（高速） |
| **判定基准** | **6 字/秒**（唯一） |
| >6 字/秒 | 需授权，仅短句 |
| 单句 >24 字 | **强制拆 2–3 镜，每镜 ≤18 字** |
| 停顿 | 逗号 ≈0.2s / 句号问号叹号 ≈0.4s / 省略号 ≈0.6–1.0s / 开口前后 ≥0.5–1.5s |
| 对话段密度 | ≥2.0 字/秒（15s ≥30 字）；开口 ≥6 次/15s |
| 混合段 | ≥1.2 字/秒 |
| VO+OS | ≤60–80 字/分钟（15s ≤20 字）；段内 OS ≤2 镜 / VO ≤1 镜 |
| 金句后 | 留 0.3–0.8s 反应镜 |

### 镜头配额

| 项 | 限额 |
|:---|:---|
| 固定镜 | ≤10%，且不连排 ≥3 |
| 运镜族 | ≥4 种（对话/文戏段豁免） |
| 人物特写占比 | ≥25% |
| 中景/全景 | 禁 90° 正拍，须 30°–60° |
| 滑动变焦 | ≤1 |
| 环绕 | ≤3 |
| 荷兰角 | ≤1 |
| 升降 | ≤2 |
| 手持剧烈 | ≤3 段 |

### 节奏守恒

| 项 | 值 |
|:---|:---|
| 总时长 | 可比剧本标注**短 25%**，宁短勿拉 |
| 一句 ≤40 字动作行 | ≤6s |
| 无台词氛围镜 | ≤5s；纯氛围段 ≤10s |
| 钩子台词 | 必须落 00:00–00:05 |
| 技巧型转场 | 单集 ≤3 处，同段不连用 ≥2 |
| 空镜 | 每集 ≤3 处；空镜开场每段至多 1 镜 |

### 台词完整性（4-gram 覆盖率）

| 覆盖率 | 判定 |
|:--:|:---|
| <0.5 | 缺失，必须回退补齐 |
| <0.85 | 部分覆盖，逐条核对 |
| ≥0.85 | 通过 |

基线是**上游分镜稿**。

## 七 · 一句话

> **符不成，法不灵。**
> 投喂不是"写得好不好"，是"格式对不对"。格式对了，普通句子也出片；格式错了，好句子也废。
