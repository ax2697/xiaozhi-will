### 9.1 最高原则 · Asset-First 六阶段（与本集门禁一一对应）

**P0 立项锁定**（画幅/风格/平台/时长）→ **P1 剧本五阶门控** → **P2 数字资产包**（提取实体→清单确认→角色/场景/道具分批出图锁定→资产图册）→ **P3 空间调度＋分镜** → **P4 投喂生成**（每段≤15s、三层解耦）→ **P5 质检**。 三铁律：①**资产图先于分镜**；②"名字＋装扮"不是资产、可直接投喂的锁定图才算；③**无图不进分镜，@锚点必须指向已锁定资产图**。对应本剧：三包＋各资产文件夹已锁图即《资产图册》；角色未锁定不出关键帧。

### 9.3 P4 投喂六步必查序列（出视频提示词按序过，缺一阻断；细则见 ★ prompt-feeding-checklist.md）

### ①~③ 开写前

- **①模板与时长预算**：组数＝成片秒数÷12~15s；每组≤15s、3~4 镜、单镜 3~5s，高动态微步进 0.5~1s；每组自带从 00:00 的完整时间轴/画幅/@资产/负向
- **②画幅路由**：顶部声明【画幅】、每条回填锁定值，本剧＝【画幅】、零回落竖屏
- **③镜头规格**：五要素[景别·视角角度·运镜·跟随目标]；中全景禁 90°正拍用 30~60°斜角；相邻镜景别阶梯跃迁、同运镜≤2s

### ④~⑥ 出稿前

- **④对白三查（有对白必过）**：台词时长≤镜预算（超时 P0 拆镜，单句>24 字拆）；金句后留 0.3~0.8s 反应镜；语速卡是内部 QC、不入投喂正文
- **⑤战斗档二选一不混用**：R3 玄幻 xuanhuan／武侠现代 action-previs；Seedance2.5 标 Hit-Stop 0.1s 与 [SFX:]
- **⑥出稿质检**：P0 时长/台词/跳轴/画幅/@锚点；P1 受力/节奏/光源；P2 无空镜/反形容词（落实 SOP 2.0）/声音三层电平

### 9.4 边界（防止两套体系打架）

> skill 给方法与检查维度；具体数值与内容（【画幅】、【出图模型】 / 【视频模型】、【帧率】、角色锚点、场景布局、台词原文）一律以本剧磁盘 .md 为准。skill 默认竖屏 9:16、R2 商业高燃档本剧不默认采用（本剧＝【画幅】、【风格】）；打戏/玄幻/武学库本集基本不用。即使引用 skill 结论，仍须回本集逐字复制固定段、过 SOP 与本卡全部门禁，不因 reference 标★权威而跳过本集流程。
