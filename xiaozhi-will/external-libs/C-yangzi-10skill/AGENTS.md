# V3 全平台单包路由

本目录是一个全平台安装包，不是两个供学员选择的版本。

## 平台入口

- Codex：进入 `01-Codex完整工程版`，按其中 `AGENTS.md` 自动安装 10 Skill；用户不需要手工解压 ZIP。
- 豆包工作模式、千问工作台：读取 `02-千问豆包OpenCode通用版/01-通用总控系统指令.txt` 与对应专业模块。
- OpenCode：用户先解压同一个 ZIP，再打开本总目录；随后读取 `02-千问豆包OpenCode通用版/AGENTS.md`。
- 其他 Agent：有本地文件与命令权限时使用通用目录；没有权限时不得声称已经安装、检索 SQLite 或写入项目文件。

任何平台都不得要求用户另下载第二个版本。包内两个适配目录只解决平台协议不同，不代表两套课程或两套创作逻辑。
