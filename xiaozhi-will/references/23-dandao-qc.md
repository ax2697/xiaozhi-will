# 23 · 还丹 · 机检与验收（道教改写）

> **归位**：六阶 · 还虚（P5 质检交付）
> **来源**：漫剧老李 V7.4.26 `sd-qc-engine`（MIT），机检手册 74KB
> **改写**：用道教"九转还丹"逻辑重组——**丹成不成，不靠感觉，靠验**。

---

## 总纲：九转还丹，转转为验

内丹讲"九转"——不是炼九次，是**九次验**。每次验完才进下一转。

质检也是：**不是"看一眼觉得行"，是"逐条验过"**。

> **判据**：**FAIL 清零才交付。** 一条不过，不许交。

---

## 一 · 三种验法，不许混用

道教验丹有三种：**看色、听声、问心**。三种不能互相冒充。

| 类 | 名称 | 谁验 | 验什么 | **怎么验**（执行动作） | 铁律 |
|:--:|:---|:---|:---|:---|:---|
| **M** | 机器可判 | 脚本 | 字数、时长、镜数、编号、结构 | 跑脚本，**留回执文件**（含命令、日期、退出码） | **不得用 M 的证据冒充 S/H 已完成** |
| **S** | AI 语义 | 模型自检 + 台账 | 逻辑、连续、表演、语义一致 | 逐条写「**判定 + 依据在哪**」（第几镜/哪句台词）；写不出依据 = 未验 | **不得把 S 判断题塞进正则** |
| **H** | 人工 | 人眼 | 真正好看、真正接得上 | ① **真打开播放一遍**；② 写「**哪一镜让我出戏**」；③ 说不出问题也要写「看完全片，无出戏点」+ 时长 | **不得跳过** |

> **H 类的具体判据**（「好看」「接得上」不是感觉，要落成两问）：
> - **接得上**：前一镜的**脸 / 服装 / 光向 / 道具位置**，后一镜是否一致？（四项逐项看）
> - **好看**：**随便暂停在哪一帧，说不说得清画面里在发生什么？** 说不清 = 观众也会懵。
>
> **最常见的糊弄**：跑了一遍脚本全绿，就说"质检通过"。
> **那只是 M 过了。S 和 H 一题没答。**

## 二 · C 系机检（Seedance 侧）· 八大组

**脚本**：`scripts/validate_prompt.py --model 2.5` 或 `--model 2.0`
**对外报 C1~C26**（编号不重排），C27–C33 为增量；**共 99 个子码**。

### 组 1 · 结构与预算（FAIL 为主）

| 码 | 检什么 |
|:--:|:---|
| C1 | 段时长 ≤ 模型上限（2.5=30s / 2.0=15s） |
| C2 | 镜头数 ≤ ceil(段长/3s)；单镜 <3s 告警 |
| C3 | 时间轴无断档/重叠；time 倒挂拦截 |
| C4 | 单文件 ≤4500 字符 |
| C5 | 版本语法：2.0 禁 `[SFX:]` 与顿挫词；2.5 建议 `[SFX:]` |
| C6 | 画幅三处互校：`aspect_ratio=` 字段 / 字段值 vs 声明 / 任务锁 `--aspect`，矛盾即 FAIL |
| C7 | 七段式结构；**镜行解析失效 → FAIL**（镜级判据全未生效，PASS 不可信） |
| C8 | 2.0 出现首帧/尾帧/参考图绑定 → 拦 |
| C9 | 平台高危词拦截 |

### 组 2 · 节奏与画外声（WARN 为主）

| 码 | 检什么 |
|:--:|:---|

| C12 | 否定式 / 工作流规则词 / 转场术语裸写进正文 → WARN |
| C13 | 同段 ≥4 镜时，同值镜长占比 ≥70% → 告警 |
| C14 | 画外声三项 FAIL：OS 画面段含开口词 / OS·VO 写进台词字段 / 用 `{}` 锁口型 |

## 四 · 连续性台账（三本账）

把锁定剧本 + 资产台账 + 分镜与投喂稿**合并为单一事实源**。

### 人物账

| 项 | 记什么 |
|:---|:---|
| 站位 | 段初位置 + 依托物 |
| 朝向 | 必须合轴线 |
| 服装造型 | **基础层与 LOOK 层分开** |
| 道具持拿 | 持有者 / 左右手 / 完损；**离手必有落点** |
| 姿态状态 | |
| 表情动作口头禅 | 须登记：来源 + 触发条件 + 频率上限 + 禁用场景 |
| 声音身份 | |

### 场景账

固定物 / 天气时间 / 光源 / 空气介质 / 尺度参照 / **空间损毁**（各带状态区间与解除节拍）。

### 时间轴账

入口时间 → 节拍时长 → 出口时间。**整数秒口径**。段时长 ≤ 上限。台词按语速倒推。

### 写法

每场按 JSON 模板：

```
entry_state → changes（每处变化挂 beat_id）→ exit_state
+ must_carry_forward（须带进下一场的状态）
+ unresolved_conflicts
```

### 跨段四条生死线

| # | 线 |
|:--:|:---|
| 1 | **摆位必入画** |
| 2 | **入画要交代** |
| 3 | **新面孔首现要交代** |
| 4 | **站位不漂移** |

### 冲突优先级

```
用户硬约束 > 剧本事实 > 已锁定设计 > 资产依据 > 保守假设
```

> **只写台账与报告，不改任何上游文件。**

## 五 · 转场门

### 导演镜头策略四选一（不得并存）

| 策略 | 必要条件 |
|:---|:---|
| TRUE_ONE_TAKE | 禁切区非空、零切镜指令、每段恰 1 个 shot_id |
| SIMULATED_ONE_TAKE | 禁可见切点、仅批准隐藏缝且须 `seam_conditions` |
| CUT_COVERAGE | 至少 1 个已批准切点 |
| HYBRID | 有切点且 no_cut_zones 非空 |

### 转场优先级

```
硬切 > 动作匹配 > 视线匹配 > 道具匹配 > 声音桥
```

叠化 / 黑白场 / 甩镜 / 压缩蒙太奇 **须写叙事依据**。

### 禁止段界 7 类

| # | 禁在哪切 |
|:--:|:---|
| 1 | 单词 / 不可分语义中间 |
| 2 | 台词已出但反应未现 |
| 3 | 动作起势与受力之间 |
| 4 | 道具离手未落点 |
| 5 | 机位未稳 |
| 6 | 禁切区内切镜 |
| 7 | **为凑 15 秒加的空镜 / 重复 / 停顿** |

### 长台词跨段

只在**已有标点 / 换气 / 语义分句**处拆。逐字顺序不变。标 `CLAUSE_HEAD/MIDDLE/TAIL` + `split_anchor`。
无安全分点 → 标 `BLOCKED` 回上游。

## 六 · 阶段验收表（六阶段 · M/S/H 分工）

> **「不能只检查」= 只查这个必漏；「还要检查」= 漏了这个必翻车。** 两列都要过。

| 阶段 | 交付物 | 不能只检查 | 还要检查 | 校验 | **怎么验**（执行动作） |
|:---|:---|:---|:---|:--:|:---|
| **P1** 剧本 | 剧本包 | 格式 | 台词/结构/来源 | M+S | 格式＝跑机检；台词＝遮名读5句；来源＝逐句标剧情源行号 |
| **P2** 资产 | 三包 | 图有无 | 首行声明 M0/M1/M2 | M+S | **数**每个资产目录下 `.png` 个数（不是看有没有文件夹）；**打开首行**核 M0/M1/M2 声明 |
| **P3** 调度+分镜 | 分镜表+机位图 | 字段齐 | C11 接续状态 | S（+M） | 字段＝**数**是否 =10；C11＝查每镜「接续状态」栏有没有填 |
| **P3′** 故事板 | 故事板 | 格数 | 出口帧=下段入口帧 | M+S（M2 加 H） | 格数＝数格子对声明；出口帧＝**把上段最后一帧与下段第一帧并排比** |
| **P4** 投喂 | 提示词组 | 七段齐 | 六道闸门 | M+S | 七段＝逐段点名；六闸＝逐闸看有没有标记通过 |
| **P5** 质检 | 报告 | 分数 | 真看过 | M+S+H | 分数＝看报告数值；真看过＝**要观看记录/出戏点清单**，没有＝未验 |

> **「声称完成」不算完成。** P3′ 与 P5 最易虚报，**必须交可核对产物**。
> **P2 的「图有无」要用数的，不是看有没有文件夹**——空目录最容易被当成"已有"。
