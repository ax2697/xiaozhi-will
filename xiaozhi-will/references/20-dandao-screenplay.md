# 20 · 炼己筑基 · 剧本结构与钩子（道教改写）

> **归位**：二阶 · 采药（P1 剧本）
> **来源**：漫剧老李 V5.0.2 剧本工业化系列（MIT），原文在 `external-libs/D-laoli-suite/legacy-v5/`
> **改写**：用道教"炼己筑基"的逻辑重组——**先立骨，再聚气，后成丹**。

---

## 总纲：剧本是炼丹的"药物处理"

内丹第一步不是点火，是**处理药物**——洗、切、蒸、晒。药处理不好，火再准也炼不出丹。

剧本就是药物的处理工序。**它决定后面所有环节的上限。**

> **一句判据**：**剧本弱，不是"拍不好"，是"根本拍不出来"。**

### 炼己四步

| 步 | 道名 | 做什么 | 落在哪 |
|:--:|:---|:---|:---|
| 一 | **立骨** | 定结构：钩子 / 冲突 / 反转 / 卡点 | 本文件 §一–§四 |
| 二 | **聚气** | 造情绪：爽点与憋屈的配比 | 本文件 §五 |
| 三 | **洗药** | 去杂质：删庸俗、去注水 | 本文件 §六 |
| 四 | **验药** | 过检：95 分制 | `templates/A5` |

## 一 · 立骨 · 开篇钩子（前 3 秒定生死）

### 道教原义：一阳初动

丹道讲"一阳来复"——冬至子时，一阳初生，此时采药最真。
**开篇就是这一阳。** 三秒内不生，后面全废。

### 铁律

> **开局 3 秒必须交代「谁、当众、用什么最痛的方式受辱」。**
> ⛔ **禁止**：日常建置 / 黑屏缓摇 / 风景空镜 / 字幕铺垫。

### 三式钩子

#### 式一 · 物证砸脸（痛感最强）

| 项 | 内容 |
|:---|:---|
| **画面** | 第一帧：一纸协议（离婚 / 退婚 / 破产 / 顶罪）或一叠钞票，**直接砸在主角脸上**，纸张空中飞散 |
| **声** | 清脆耳光声，或纸张击脸的"啪"闷响 |
| **台词** | `"沈惊秋。签了它，滚出顾家。"` |

> **为什么最痛**：物证有实体，观众能"感觉到重量"。

#### 式二 · 错位跪迎（期待值最强）

| 项 | 内容 |
|:---|:---|
| **画面** | 奢华宴会厅，十几个西装大佬整齐弯腰九十度、双手奉金卡。镜头拉开——**他们跪迎的是一个穿外卖服、满头汗的底层青年** |
| **声** | 雷鸣般整齐的军靴踏地 / 皮鞋碰撞 |
| **台词** | `"恭迎，龙王回归！"` |

> **为什么最强**：观众立刻产生"这人有秘密"的好奇——**好奇心比同情心更抓人**。

#### 式三 · 反常危机（悬疑最强）

| 项 | 内容 |
|:---|:---|
| **画面** | 特写：一滴血从手术刀（或银针）尖滑落，滴在地毯。反打——**主角正冷静地缝合一个黑衣人**，神色淡漠 |
| **声** | 重低音 BGM 切入，尖锐金属破空啸声 |
| **台词** | `"你……到底是谁？"` |

> **为什么最悬**：**主角在做一件不该这么熟练的事**——反常即钩。

## 二 · 立骨 · 冲突（必须有见证链）

### 道教原义：借势

丹道讲"借天地之炁"。一个人闭门打坐，炁不聚；要借日月山川之势。

**冲突也一样**：没有见证者的冲突，等于零。

> **铁律**：冲突必须有「**群体见证链**」。

### 两式

#### 式一 · 众目睽睽下的道德压榨

| 项 | 内容 |
|:---|:---|
| **场景** | 寿宴 / 同学会 / 订婚宴 / 公司年会（**有头有脸的人在场**） |
| **动作** | 反派当着所有人，端一杯滚烫茶水（或红酒）"失手"泼在主角便宜衣服上，反大声呵斥主角弄脏了高贵场所 |
| **见证反应** | 逐个特写宾客：交头接耳 / 捂嘴嗤笑 / 幸灾乐祸 |
| **声** | 酒杯砸碎脆响 + 密集窃窃私语 |
| **台词** | `"沈惊秋，这一杯酒，抵你沈家十年的命！"` |

> **关键在"逐个特写"**：不是拍一群人，是**一个一个拍他们的脸**。观众才记住"多少人看见了"。

#### 式二 · 真假马甲的智商碾压

| 项 | 内容 |
|:---|:---|
| **场景** | 谈判桌 / 学术会 / 抢救室（**有专业权威在场**） |
| **动作** | 伪善者拿着剽窃主角的方案在台上宣称是自己发明，主角安静站在台下，等到最关键卡点 |
| **反转** | 主角不长篇大论，直接指最微小的漏洞：`"第三页，第九行。参数，错了一位数。"` |

> **为什么这么设计**：一句话击穿，比十句咆哮有力。**丹道讲"一针见血"，就是这个。**

## 三 · 立骨 · 反转（信息差的足额兑付）

### 道教原义：逆则成丹

顺行是常人路，逆行才是丹道。
**反转就是叙事上的"逆行"**——观众以为顺，你偏逆。

> **本质**：**让反派在最高傲的时刻坠入深渊。**

### 两式

#### 式一 · 多层马甲递进（三格引爆）

```
格一 · 疑
  反派欺负主角是普通前台，要开除他
        ↓
格二 · 露
  主角不慌不忙拿出总公司金徽章卡片
  分公司经理脸色微变，但仍大骂伪造、叫嚣报警
        ↓
格三 · 炸
  总公司总裁破门而入，看到主角瞬间轰然跪地
  分公司经理瞳孔收缩，直接吓瘫
```

**关键视觉**：反派瘫软 / 名贵玉扳指或咖啡杯在台阶上摔碎的特写。

> **为什么是三格不是一格**：一格反转是"意外"，三格是"层层剥开"。
> **每一格都要给对方一个"还不信"的理由**，第三格才炸得响。

#### 式二 · 降维借力（高位狙击）

| 步 | 内容 |
|:--|:---|
| **铺** | 反派自诩资产十亿，不可一世，疯狂拨通最大靠山（帝都第一财阀家主）的电话，要求封杀主角 |
| **爆** | 电话接通瞬间，主角在旁边冷冷说三个字：`"顾城。跪下。"` |
| **炸** | 电话那头大靠山撕心裂肺咆哮，要求反派**立刻跪下道歉，否则灭其全族** |

> **为什么有效**：**观众要看的不是主角有多强，是"反派发现主角有多强"那一刻的表情。**

## 四 · 立骨 · 卡点（切在最中间）

### 道教原义：留一线

丹道讲"火候到时，留一线不烧尽"——全烧完了，下一炉没引子。

**卡点就是留那一线。**

> **铁律**：**永远切在动作、真相或决定的最中间。**
> ⛔ **严禁**切在事件交代完毕后。

### 三式卡点

#### 式一 · 动作腰斩（付费解锁率最高）

```
【画面】巴掌距离林默的脸仅剩两公分，掌风吹起他的额发
【音效】BGM 急促电音重音瞬间拔高
【画面】突兀切黑，全集终
```

> **那两公分，就是钩子。** 差一公分都不行——太近已打脸，太远没张力。

#### 式二 · 两难抉择

```
【画面】反派拇指按在扳机机头上，金属咬合"咔哒"
【台词】"林默，最后三秒。选吧。"
【音效】尖锐高频耳鸣拉长，切黑，全集终
```

#### 式三 · 身份呼之欲出

```
【台词】大医令（颤抖，手指指向）：你……你难道是当年救活太子的……沈神……
【音效】重音"咚"轰鸣，切黑，全集终
```

> **注意**：名字**只说一半**。说完就没钩子了。

## 五 · 聚气 · 爽点与憋屈的配比

### 道教原义：阴阳相济

独阳不生，孤阴不长。**只有爽没有憋，爽就廉价；只有憋没有爽，观众弃剧。**

### 配比公式

```
憋屈 : 爽点  ≈  3 : 1（前期）
憋屈 : 爽点  ≈  1 : 1（中后期）
```

> **为什么前期要 3:1**：前 3 集压得越狠，第一次打脸越爽。
> **为什么后期要 1:1**：一直压会疲，要开始给糖。

### 与"承负"联动

参见 `19-dandao-mechanisms.md` 机四·还债：

```
打脸释放能量 ≥ 2 × 憋屈时长 × 羞辱公开度
```

**配比是节奏，承负是总量。** 两个都要算。

## 六 · 洗药 · 去杂质

### 道教原义：洗药去毒

采来的药不能直接入炉——要洗、要泡、要去毒。**不去毒，补药变毒药。**

### 三洗

| 洗 | 去什么 | 怎么去 |
|:--:|:---|:---|
| **一洗 · 庸俗** | 烂大街的桥段、用滥的台词 | 对照"庸俗 vs 升级"对照表 |
| **二洗 · 注水** | 无信息量的对话、重复情绪 | 每句问：删了影响理解吗？不影响就删 |
| **三洗 · 冒犯** | 违规情节、敏感内容 | 对照合规清单替换 |

> **一句判据**：**能删的都删掉，剩下的才是戏。**

## 七 · 篇幅：60 秒与 90 秒的差别

| 项 | 60 秒 | 90 秒 |
|:---|:---|:---|
| **钩子** | 必须 3 秒内 | 可 5 秒内 |
| **冲突数** | 1 个 | 1–2 个 |
| **反转** | 1 次 | 1–2 次 |
| **卡点** | 1 个硬钩 | 可软钩 |
| **台词密度** | 极高，每句必推 | 可留一口气 |

> **60 秒是匕首，90 秒是短刀。** 别拿匕首的写法套 90 秒——会显得空。

---

## 八 · 多分支互动剧（特殊形态）

互动剧不是"多写几条线"，是**在关键节点分叉**。

| 项 | 规则 |
|:---|:---|
| **分叉点** | 只在"抉择时刻"分，不在"信息揭示"处分 |
| **分支数** | 单点 ≤3 条（多了观众记不住） |
| **回收** | 分支必须能合流，否则后期成本爆炸 |
| **每条分支** | 独立成立，不能"选错就废" |

## 九 · 自查（写完必过）

- [ ] 前 3 秒有钩子，且是"当众受辱"
- [ ] 冲突有群体见证链，且逐个特写
- [ ] 反转至少两层（不是一次性揭底）
- [ ] 卡点切在动作/真相/决定中间，不切在交代后
- [ ] 憋屈:爽点 配比符合阶段
- [ ] 有承负账本，实还 ≥ 应收
- [ ] 三洗已过（庸俗 / 注水 / 冒犯）
- [ ] 篇幅匹配（60 vs 90 写法不同）
- [ ] 台词 ≤24 字单句（中文）/ ≤10 词（英文）
- [ ] 过 A5 的 95 分制
